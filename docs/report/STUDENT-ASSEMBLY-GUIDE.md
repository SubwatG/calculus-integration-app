**โครงการ Calculus Learning Sandbox (Calculus Integration Application)**

## 1. ไฟล์ผลลัพธ์สำเร็จรูปที่เตรียมไว้ให้

ในโฟลเดอร์ `docs/report/` ทีมพัฒนาได้เตรียมไฟล์รายงานโครงงานไว้ให้ 2 รูปแบบ:

1. **ฉบับรวมเล่มสมบูรณ์ (แนะนำ):**
   * **`full-project-report-master.docx`** — รวมเนื้อหาครบทุกบทตั้งแต่ บทคัดย่อ, บทที่ 1–5, บรรณานุกรม, จนถึงภาคผนวก ก–จ ไว้ในไฟล์เดียว พร้อมจัดฟอนต์ TH SarabunPSK 16pt, ย่อหน้า 1.2 ซม., ระยะบรรทัด และรูปแบบตาราง/ภาพตามระเบียบเรียบร้อยแล้ว
2. **ฉบับแยกรายบท:**
   * `abstract.docx` (บทคัดย่อภาษาไทยและอังกฤษ)
   * `chapter-01-introduction.docx` (บทนำ)
   * `chapter-02-background.docx` (ทฤษฎีและเทคโนโลยี)
   * `chapter-03-methodology.docx` (วิธีดำเนินงานและสถาปัตยกรรม)
   * `chapter-04-results.docx` (ผลการดำเนินงาน สถิติความพึงพอใจ และ SUS)
   * `chapter-05-conclusion.docx` (สรุปผล อภิปราย และข้อเสนอแนะ)
   * `references-bibliography.docx` (บรรณานุกรม)
   * `appendix-a-survey.docx` ถึง `appendix-e-biography.docx` (ภาคผนวก ก–จ)

## 2. ขั้นตอนการนำไปใช้ส่งอาจารย์และกรรมการสอบ (3 ขั้นตอนง่ายๆ)

### ขั้นตอนที่ 1: เปิดไฟล์ `full-project-report-master.docx` ใน Microsoft Word
* ตรวจดูภาพรวมของเอกสาร การขึ้นหน้าใหม่ของแต่ละบท (Page Break) และความเรียบร้อยของสมการและรูปภาพ

### ขั้นตอนที่ 2: เพิ่มหน้าส่วนหน้า (Front Matter) ตามระเบียบมหาวิทยาลัย
นำเทมเพลตของคณะ/มหาวิทยาลัยมาประกบไว้ที่ส่วนหน้าสุดของเอกสาร:
1. ปกนอก และ ปกใน
2. ใบรับรองโครงงาน (ใบอนุมัติที่มีลายเซ็นอาจารย์ที่ปรึกษาและกรรมการ)
3. กิตติกรรมประกาศ (Acknowledgment)
4. สารบัญ, สารบัญตาราง, สารบัญภาพ (สามารถใช้เมนู `References -> Table of Contents` ของ Word เพื่อสร้างสารบัญอัตโนมัติจากสไตล์ Heading 1-3 ที่ระบบจัดไว้ให้แล้ว)

### ขั้นตอนที่ 3: ตั้งค่าเลขหน้า (Page Numbering)
* **ส่วนหน้า (บทคัดย่อ, กิตติกรรมประกาศ, สารบัญ):** ใช้เลขหน้าแบบตัวอักษรไทย เช่น ก, ข, ค, ง...
* **ส่วนเนื้อหา (เริ่มตั้งแต่บทที่ 1 เป็นต้นไป):** ใส่ `Section Break (Next Page)` ก่อนบทที่ 1 แล้วตั้งค่าเลขหน้าเป็นเลขอารบิก เริ่มต้นที่หน้า **1**

## 3. วิธีสั่งสร้างไฟล์ใหม่ด้วยตนเอง (หากมีการแก้ไขเนื้อหาใน QMD)

หากนิสิตมีการแก้ข้อความในไฟล์ `.qmd` สามารถสั่งรวมเล่มใหม่ได้ง่ายๆ ด้วยคำสั่งเดียวใน Terminal:

```bash
cd docs/report
python3 build_master_report.py
```

สคริปต์จะทำการประกอบไฟล์และสั่งเรนเดอร์เอกสาร Word ทุกไฟล์ใหม่อัตโนมัติทันที
