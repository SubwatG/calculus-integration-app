# ผลทดลองใช้งานผ่าน browser-box และแผนแก้ไข

## วิธีทดสอบ

เปิดแอปจริงด้วย `.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8502 --server.headless true --browser.gatherUsageStats false` ตรวจ health endpoint ได้ `ok` แล้วใช้ browser-box เปิด `http://127.0.0.1:8502`

ตรวจ DOM ของหน้าจอจริงหลังการโต้ตอบ รวมค่าที่อยู่ใน input, LaTeX annotation ที่ KaTeX ใช้แสดง, ข้อความแจ้งเตือน และสถานะการโหลดภาพ ไม่ได้เรียก helper แทนการทดสอบหน้าจอ ไม่ได้ฉีด session state ของแอป

การกรอกด้วย helper บางครั้งเปลี่ยนเฉพาะค่าใน DOM โดย Streamlit ยังไม่รับค่า จึงใช้ native HTMLInputElement value setter, ส่ง input event และกด Enter ด้วย `browser_press_key` จากนั้นอ่านค่ากับสมการกลับเพื่อยืนยันว่าระบบรับข้อมูลจริง ทิ้งผลจากความพยายามที่ยังเป็นค่าเดิม ไม่ใช้เป็นข้อบกพร่องของแอป

หลักฐานอยู่ใน `browser-evidence.json` จำนวน 7 สถานการณ์ มีการโต้ตอบแบบสอบถามเฉพาะ quiz ในเซสชันทดสอบ ไม่ได้ส่งแบบประเมินภายนอก

## ผลที่ยืนยันบนหน้าจอ

| สถานการณ์ | ผลจริง | ข้อสรุป |
|---|---|---|
| ลิมิต $1/x$ ที่ $0$ | แสดงด้านซ้ายเป็น $-\infty$ ด้านขวาเป็น $\infty$ แต่ขั้นสรุปเขียนว่าทั้งสองเท่ากัน | ยืนยันข้อผิดพลาดในการสรุปลิมิตสองด้าน |
| พื้นที่ $f(x)=x$, $g(x)=0$ บน $[-1,1]$ | แสดง $A=0$ | เป็นปริพันธ์มีเครื่องหมาย ไม่ใช่พื้นที่เรขาคณิต $1$ และไม่มีคำเตือนเรื่องเงื่อนไขบน/ล่าง |
| กราฟของกรณีพื้นที่ข้างต้น | แจ้ง `x and y must have same first dimension, but have shapes (400,) and (1,)` และไม่มีภาพกราฟ | พบข้อบกพร่องเพิ่มเติมในการพล็อตฟังก์ชันค่าคงที่ |
| ปริพันธ์ $1/x^2$ บน $[1,2]$ | แสดงค่าถูกคือ $0.5$ แต่สมการผลลัพธ์หลักใช้ขอบบน $\infty$ | ยืนยันข้อผิดพลาดการแสดงสมการ ช่วงในวิธีทำยังเป็น $[1,2]$ |
| รีมันน์ $x^2$ บน $[0,2]$, ซ้าย, $n=8$ | แสดง $2.187500$ และภาพกราฟโหลดสำเร็จ | ค่าตรงกับ finite sum อ้างอิง $35/16$ |
| quiz ตอบผิดครั้งแรก | แสดงคำใบ้ คะแนนยังเป็น $0$ และยังอยู่ข้อแรก | ผ่านกรณีคำใบ้ก่อนเฉลยที่ทดลอง |
| quiz แก้เป็นคำตอบถูก | คะแนนเพิ่มเป็น $1$ และแสดงคำอธิบาย | ผ่านกรณีให้คะแนนที่ทดลอง |
| ไปหน้า history แล้วกลับ quiz | คะแนน $1$ และคำตอบข้อแรกยังอยู่ | ผ่านการคงสถานะข้ามหน้าที่ทดลอง |

ตารางแยกข้อบกพร่องกราฟออกจากสถานการณ์พื้นที่เดียวกัน จึงไม่ใช่จำนวน record เท่ากับจำนวนแถว ขณะยังทำ quiz ไม่ครบ หน้า history แสดงว่ายังไม่มีประวัติ โค้ด `pages/quiz.py` บันทึก `quiz_scores` หลังทำชุดเสร็จ จึงยังไม่จัดการไม่มีประวัติระหว่างทำเป็น bug

การพบภาพกราฟโหลดสำเร็จไม่รับรองความถูกต้องของรูปร่าง สี ฟอนต์ หรือ mobile layout ยังไม่ได้ตรวจ visual QA แบบภาพและยังไม่ได้ทดลองทุกหน้า/ทุกกรณีในแผน

## แผนแก้ไขเรียงตามความเสี่ยง

### 1. สรุปลิมิตสองด้านให้ถูกต้อง

- เป้าหมาย: `utils/limit_solver.py`, `utils/sympy_solver.py` และหน้าแสดงผลที่เกี่ยวข้อง
- เขียน regression test ของ $1/x$ ที่ $0$ ก่อนแก้ ให้จำแนกซ้ายและขวาไม่เท่ากันว่าไม่มีลิมิตสองด้าน
- รักษาการวินิจฉัยลิมิตอนันต์สองด้านเมื่อทั้งสองข้างลู่ไปอนันต์เดียวกัน แยกจากกรณีไม่มีลิมิต
- เกณฑ์ผ่าน: ไม่มีสมการอ้างว่าค่าต่างกันเท่ากัน และกรณีปกติ เช่น $\sin(x)/x$ ที่ $0$ ยังได้ $1$

### 2. พื้นที่เรขาคณิตและเงื่อนไขฟังก์ชันบน/ล่าง

- เป้าหมาย: `utils/area_solver.py`, `pages/area_between.py`
- ตกลง contract ให้ชัด: คำนวณ $\int_a^b |f-g|\,dx$ โดยแยกช่วงตามจุดตัด หรือจำกัดให้ฟังก์ชันบนไม่ต่ำกว่าล่างตลอดช่วงและแจ้งข้อจำกัดอย่างชัดเจน
- คำแนะนำ: สำหรับหน้าที่ให้ผู้ใช้ทดลองฟังก์ชันเอง ให้รองรับการแยกช่วงและรายงานจุดตัด หากหาจุดตัดหรือโดเมนไม่ได้อย่างน่าเชื่อถือ ต้องแจ้งข้อจำกัด ไม่ใช้ค่ามีเครื่องหมายเป็นพื้นที่
- เกณฑ์ผ่าน: กรณีตัดกันได้พื้นที่ $1$ หรือคำเตือนที่มีเหตุผล ไม่แสดงพื้นที่ติดลบหรือศูนย์อย่างทำให้เข้าใจผิด

### 3. พล็อตฟังก์ชันค่าคงที่

- เป้าหมาย: `utils/plotter.py` และ plot helpers ที่รับผลจาก `lambdify`
- ตรวจผลลัพธ์ scalar ของฟังก์ชันคงที่และแปลงให้มี shape เดียวกับจุดตัวอย่างก่อน plot/fill
- เพิ่ม regression tests ของ $f(x)=0$ และค่าคงที่ไม่เป็นศูนย์ แยกจากการทดสอบค่าพื้นที่
- เกณฑ์ผ่าน: ไม่เกิด shape mismatch, รูปโหลด และแกน/ช่วงตรงกับ input

### 4. ขอบเขตและสถานะปริพันธ์ไม่ตรงแบบ

- เป้าหมาย: `utils/improper_solver.py`, `pages/improper_integrals.py`
- ใช้ขอบบนจริงในการสร้าง LaTeX และจำแนกผลเป็นค่าจำกัด ลู่ออก หรือยังคำนวณไม่ได้
- เพิ่ม regression tests ทั้งช่วงอนันต์ ช่วงจำกัดที่มี singular endpoint และช่วงจำกัดปกติ
- เกณฑ์ผ่าน: ปริพันธ์ $1/x^2$ บน $[1,2]$ แสดงขอบบน $2$ และค่า $1/2$; กรณี $1/x$ บน $[1,\infty)$ ระบุว่าลู่ออกชัดเจน

### 5. Validation และทดสอบย้อนกลับ

- อนุมัติข้อเสนอเรื่อง `n` ต้องเป็นจำนวนเต็มและการปฏิเสธ `washer` ที่ยังไม่มีรัศมีด้านในจริงก่อนเพิ่มข้อกำหนด
- หลังแก้แต่ละส่วนรันชุดเดิม ชุดโจทย์ใหม่ และทดลอง browser-box ด้วย input เดิมอีกครั้ง
- เก็บหลักฐานก่อน/หลัง ไม่เปลี่ยนเฉลยให้ตรงกับผลผิด และไม่ถือว่า helper ผ่านแล้วหน้าจอผ่านด้วย

เอกสารนี้เป็นแผนแก้ไขพร้อมหลักฐานปัญหา ยังไม่ได้แก้โค้ดผลิตภัณฑ์
