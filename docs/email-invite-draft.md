# ร่างอีเมลถึงนักศึกษา

Subject: ขอ GitHub username สำหรับเข้าร่วมพัฒนาโปรเจกต์ Calculus Integration App

เรียน นักศึกษาทุกคน

อาจารย์กำลังเตรียม GitHub repository สำหรับโปรเจกต์เว็บแอปช่วยเรียนแคลคูลัสเบื้องต้น เรื่องอินทิเกรต โดยจะใช้เป็นพื้นที่ทำงานร่วมกันของทีมตลอดการพัฒนาโปรเจกต์

ขอให้นักศึกษาส่งข้อมูลต่อไปนี้กลับมาให้อาจารย์:

1. ชื่อ-นามสกุล
2. GitHub username
3. email ที่ใช้สมัคร GitHub
4. ระบบปฏิบัติการที่ใช้ทำงาน เช่น Windows 10, Windows 11, macOS หรือ Linux

ถ้ายังไม่มีบัญชี GitHub ให้สมัครที่:

```text
https://github.com/signup
```

หลังจากอาจารย์ส่ง invitation ให้แล้ว นักศึกษาจะได้รับแจ้งเตือนใน GitHub หรือ email ให้กดรับคำเชิญก่อน จึงจะสามารถ clone repository และ push งานได้

เครื่องมือที่ควรติดตั้งไว้ก่อนเริ่มงาน:

1. Python 3.11 หรือใหม่กว่า
2. Git for Windows
3. Visual Studio Code
4. GitHub account

เอกสารวิธีดึงโปรเจกต์ไปรันบนเครื่อง Windows จะอยู่ใน repository ที่ไฟล์:

```text
docs/windows-student-setup.md
```

เบื้องต้นให้ทุกคนเตรียมเครื่องให้พร้อมก่อน เมื่อเข้า repository ได้แล้วให้ลองรันเว็บแอปตามเอกสาร หากติดปัญหาให้จด error message หรือ capture หน้าจอไว้ แล้วส่งให้อาจารย์ตรวจสอบ
