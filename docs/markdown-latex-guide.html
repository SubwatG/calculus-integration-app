3. คำสั่ง LaTeX ที่จำเป็น

สมการคณิตศาสตร์ในแอปนี้ render ด้วยระบบเดียวกับ KaTeX ที่ Streamlit ฝังไว้ ดังนั้นคำสั่งที่ใช้ได้จึงเป็นชุดย่อยของ LaTeX มาตรฐาน แต่ครอบคลุมเนื้อหา แคลคูลัสอินทิเกรตทั้งหมดที่โปรเจกต์ต้องการ

3.1 สมการแบบ inline และ display

Inline ใช้ $...$ อยู่ในประโยคเดียวกันกับข้อความไทย:

เมื่อ $F'(x)=f(x)$ แล้ว $F(x)$ เป็นปฏิยานุพันธ์ของ $f(x)$

Display ใช้ $$...$$ แยกบรรทัดของตัวเอง เพื่อให้สมการเด่นและอยู่ตรงกลาง:

$$
\int f(x)\,dx = F(x)+C
$$

กฎบังคับของโปรเจกต์: ห้ามใช้ \(...\) หรือ \[...\] โดยเด็ดขาด เพราะ st.markdown ของ Streamlit ไม่รองรับรูปแบบเหล่านั้น

x^{n+1} \(x^{n+1}\)
x_1 \(x_1\)
a_n \(a_n\)
\ne \(\ne\)
\le, \ge \(\le\), \(\ge\)
\pm \(\pm\)
\cdot \(\cdot\)

จำง่าย: ถ้าตัวยกหรือตัวห้อยยาวเกินหนึ่งตัวอักษร ต้องครอบด้วย {...} เสมอ เช่น x^{n+1} ไม่ใช่ x^n+1 (ซึ่งแปลว่า \(x^n+1\))

3.4 อินทิเกรต

อินทิเกรตไม่จำกัดเขต (indefinite integral):

$$
\int f(x)\,dx = F(x)+C
$$

อินทิเกรตจำกัดเขต (definite integral) ใช้ตัวห้อยเป็นขอบล่าง ตัวยกเป็นขอบบน:

$$
\int_a^b f(x)\,dx = F(b)-F(a)
$$
$$

\int_a^b f(x)\,dx = F(b)-F(a)
$$

เครื่องหมาย `\,` คือช่องว่างบาง ใช้คั่นระหว่างฟังก์ชันกับ `dx` เพื่อให้อ่านง่าย

3.8 ระบบสมการ (cases)

ใช้ \begin{cases} สำหรับฟังก์ชันนิยามเป็นช่วงหรือระบบสมการ:

$$
f(x)=
\begin{cases}
x^2, & x \ge 0 \\
-x, & x < 0
\end{cases}
$$

\[ f(x)= \begin{cases} x^2, & x \ge 0 \\ -x, & x < 0 \end{cases} \]

เครื่องหมาย \\ คือการขึ้นบรรทัดใหม่ในสมการ และ & ใช้จัดตำแหน่งคอลัมน์

3.9 การจัดแนวสมการหลายบรรทัด (align)

ใช้ \begin{align*} เมื่อต้องการแสดงขั้นตอนหลายบรรทัดให้เครื่องหมายเท่ากับ อยู่ในตำแหน่งเดียวกัน:

$$
\begin{align*}
\int 3x^2\,dx &= 3\int x^2\,dx \\
&= 3\cdot\frac{x^3}{3}+C \\
&= x^3+C
\end{align*}
$$

\[ \begin{align*} \int 3x^2\,dx &= 3\int x^2\,dx \\ &= 3\cdot\frac{x^3}{3}+C \\ &= x^3+C \end{align*} \]

$$
\left( \frac{1}{x} + x \right)^2
$$

\[ \left( \frac{1}{x} + x \right)^2 \]

4. การนำไปใช้ในโค้ดของแอป

4.1 แสดงบทเรียนด้วย st.markdown

หน้า pages/lessons.py โหลดไฟล์ Markdown แล้วส่งเข้า st.markdown โดยตรง:

content = load_lesson(filename)
st.markdown(content)

ข้อควรจำ: เมื่อเขียน string ที่มี LaTeX อยู่ในโค้ด Python ต้องใช้ raw string r"..." หรือ r"""...""" เพื่อให้ backslash ไม่ถูกตีความเป็น escape sequence:

st.markdown(
    r"""
$$
\int x^n\,dx = \frac{x^{n+1}}{n+1}+C,\quad n\ne -1
$$
"""
)

4.2 แสดงสมการเดี่ยวด้วย st.latex

ถ้าต้องการสมการใหญ่เพียงสมการเดียว ใช้ st.latex() ซึ่งจะจัดวางให้โดดเด่น:

st.latex(r"\int_a^b f(x)\,dx = F(b)-F(a)")

4.3 ข้อสอบในไฟล์ JSON

ไฟล์ data/quizzes/*.json เก็บข้อสอบแบบ multiple choice ข้อความและตัวเลือก สามารถใช้ LaTeX ได้ แต่ต้องระวังว่า ใน JSON ต้องเขียน backslash เป็น \\ (สองตัว) เสมอ:

{
  "topic": "basic_rules",
  "question": "จงหา $\\int 3x^2\\,dx$",
  "choices": [
    "$x^3 + C$",
    "$3x^3 + C$",
    "$6x + C$",
    "$x^2 + C$"
  ],
  "answer": "$x^3 + C$",
  "explanation": "ใช้ power rule: $\\int 3x^2\\,dx = 3\\cdot\\frac{x^3}{3}+C = x^3+C$"
}

ข้อควรจำสำหรับ JSON:

  • ทุกข้อต้องมี field ครบ: topic, question, choices, answer, explanation
  • choices ต้องมี 4 ตัวเลือก
  • string ต้องใช้ double quotes เท่านั้น
  • ห้ามมี comma เกินท้ายรายการสุดท้าย

4.4 เครื่องคิดเลขในหน้าแก้โจทย์ (SymPy)

หน้า pages/solver.py ใช้ SymPy อ่านนิพจน์ที่ผู้ใช้พิมพ์ ดังนั้นต้องใช้ ไวยากรณ์ Python/SymPy ไม่ใช่ LaTeX:

ต้องการ พิมพ์ หมายเหตุ
\(x^2\) x**2 ไม่ใช่ x^2
\(x^3 + 2x - 5\) x**3 + 2*x - 5 ต้องมี * คูณเสมอ
\(\sin x\) sin(x) ต้องมีวงเล็บ
\(e^x\) exp(x) ไม่ใช่ e**x
\(\sqrt{x}\) sqrt(x)
เศษส่วน (x**2 - 4)/(x - 2) วงเล็บครบทั้งเศษและส่วน

# Basic Integration Rules

## Learning objectives

เมื่อเรียนจบบทนี้ ผู้เรียนควรสามารถ

1. ใช้กฎคูณด้วยค่าคงที่ได้
2. ใช้กฎยกกำลังกับ $x^n$ เมื่อ $n\ne -1$ ได้
3. เขียนคำตอบของ indefinite integral พร้อม $+C$ ได้

## Power rule

ถ้า $n\ne -1$ แล้ว

$$
\int x^n\,dx = \frac{x^{n+1}}{n+1}+C
$$

## Common mistakes

- ลืมเขียน $+C$ ในคำตอบสุดท้าย
