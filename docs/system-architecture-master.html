1. สถาปัตยกรรมระบบ 3 ชั้น และแผนภาพการไหลของข้อมูล ARCHITECTURE

ระบบนี้ถูกออกแบบตามหลักการวิศวกรรมซอฟต์แวร์ Separation of Concerns (SoC) อย่างเข้มงวด โดยแยกโค้ดการคำนวณคณิตศาสตร์ ออกจากหน้าจอแสดงผล และชุดทดสอบความถูกต้องอย่างเด็ดขาด เพื่อป้องกันไม่ให้เกิดความสับสนเมื่อนิสิตกลับมาแก้ไขโค้ด

ตำแหน่งโฟลเดอร์: utils/*_solver.py

3. ขั้นตอนวิธีทางคณิตศาสตร์: ลิมิตรูปแบบยังไม่กำหนด 0/0 utils/limit_solver.py

หัวข้อลิมิตเป็นจุดแรกที่นิสิตที่เรียนแคลคูลัสมักจะสับสน โดยเฉพาะเมื่อเจอรูปแบบยังไม่กำหนด $\left[\frac{0}{0}\right]$ นิสิตมักจะด่วนสรุปว่า "หาค่าไม่ได้" หรือไม่รู้วิธีการจัดรูปพีชคณิต โมดูลนี้จึงต้องทำหน้าที่แกะขั้นตอนอย่างเป็นระบบ

กระบวนการทางคณิตศาสตร์ 4 ขั้นตอน (Algorithmic Logic):

  1. การแทนค่าตรง (Direct Substitution Check):
    แยกนิพจน์ $f(x)$ ออกเป็นเศษ $N(x)$ และส่วน $D(x)$ ด้วย expr.as_numer_denom() จากนั้นแทนค่า $x = a$ เพื่อหาค่า $N(a)$ และ $D(a)$
    - ถ้า $D(a) \neq 0$: ลิมิตหาค่าได้ทันทีโดยการแทนค่าตรง $L = \frac{N(a)}{D(a)}$
    - ถ้า $D(a) = 0$ และ $N(a) \neq 0$: ลิมิตมีค่าเป็นอนันต์หรือหาค่าไม่ได้ (เส้นกำกับแนวดิ่ง)
    - ถ้า $D(a) = 0$ และ $N(a) = 0$: ติดป้ายสถานะเป็น รูปแบบยังไม่กำหนด (Indeterminate Form $\frac{0}{0}$) ต้องดำเนินการจัดรูปในขั้นตอนถัดไป
  2. การจำแนกประเภทโครงสร้างพีชคณิต (Pattern Classification):
    ตรวจสอบว่าในเศษ $N(x)$ หรือส่วน $D(x)$ มีพจน์ที่เป็นรากที่สอง (Square Root หรือ is_Pow ที่มีกำลังเป็น $1/2$) หรือไม่
    - กรณีที่ 1 (พหุนามตรรกยะ): ใช้ขั้นตอนวิธีแยกตัวประกอบ (Factorization Strategy)
    - กรณีที่ 2 (ฟังก์ชันติดกรณฑ์): ใช้ขั้นตอนวิธีคูณด้วยสังยุค (Conjugate Multiplication Strategy)
  3. การกำจัดตัวประกอบร่วมและการลดรูป (Simplification & Cancellation):
    หัวใจของการหาลิมิตเมื่อ $x \to a$ คือ $x \neq a$ ดังนั้นพจน์ $(x - a) \neq 0$ เราจึงสามารถตัดทอนพจน์ $(x - a)$ ที่เป็นตัวการทำให้เกิด $\frac{0}{0}$ ออกไปได้
    ได้ฟังก์ชันใหม่ $g(x)$ ที่มีนิยามที่จุด $a$
  4. การคำนวณลิมิตขั้นสุดท้าย (Final Evaluation):
    แทนค่า $x = a$ ลงใน $g(x)$ จะได้ค่าลิมิตจริง $L = g(a)$

ตัวอย่างโค้ดฉบับสมบูรณ์สำหรับ utils/limit_solver.py:

# utils/limit_solver.py
from typing import Any
import sympy as sp
from sympy.parsing.sympy_parser import (
    parse_expr,
    standard_transformations,
    implicit_multiplication_application,
)

TRANSFORMATIONS = standard_transformations + (
    implicit_multiplication_application,
)

X = sp.Symbol("x")

def _parse_input(expr_str: str) -> sp.Expr:
    clean = (expr_str or "").strip()
    if not clean:
        raise ValueError("กรุณากรอกฟังก์ชัน f(x)")
    return parse_expr(clean, transformations=TRANSFORMATIONS)

def compute_limit_near(expr_str: str, a: float) -> dict[str, Any]:
    """คำนวณลิมิต lim_{x->a} f(x) พร้อมสร้างขั้นตอนแสดงผลเชิงการสอน (Pedagogical Steps)"""
    try:
        expr = _parse_input(expr_str)
        a_sym = sp.Rational(str(a)).limit_denominator(1000)
        num, den = expr.as_numer_denom()
        steps = []

        # ขั้นตอนที่ 1: วิเคราะห์การแทนค่าตรง
        val_num = sp.simplify(num.subs(X, a_sym))
        val_den = sp.simplify(den.subs(X, a_sym))

        steps.append(
            f"**ขั้นที่ 1: ตรวจสอบโดยการแทนค่าตรง (Direct Substitution)**\n"
            f"ลองแทนค่า $x = {sp.latex(a_sym)}$ ในฟังก์ชัน $f(x) = \\frac{{{sp.latex(num)}}}{{{sp.latex(den)}}}$\n"
            f"$$f({sp.latex(a_sym)}) = \\frac{{{sp.latex(val_num)}}}{{{sp.latex(val_den)}}}$$"
        )

        if val_den == 0 and val_num == 0:
            steps.append(
                "**ขั้นที่ 2: วินิจฉัยรูปแบบยังไม่กำหนด (Indeterminate Form)**\n"
                "พบว่าผลลัพธ์อยู่ในรูป $\\left[\\frac{0}{0}\\right]$ ซึ่งยังไม่สามารถสรุปคำตอบได้ "
                "จำเป็นต้องจัดรูปทางพีชคณิตเพื่อตัดทอนตัวประกอบร่วม $(x - " + sp.latex(a_sym) + ")$ ออกก่อน"
            )

            # ตรวจจับกรณีมีเครื่องหมายรากที่สอง (Square Root) เพื่อเลือกใช้สังยุค
            has_sqrt = any(arg.is_Pow and arg.exp == sp.Rational(1, 2) for arg in expr.atoms())

            if has_sqrt:
                steps.append(
                    "**ขั้นที่ 3: การใช้สังยุค (Conjugate Multiplication)**\n"
                    "เนื่องจากฟังก์ชันมีพจน์ติดกรณฑ์ เราจะนำสังยุคของพจน์นั้นมาคูณทั้งเศษและส่วน "
                    "เพื่อใช้เอกลักษณ์ผลต่างกำลังสอง $A^2 - B^2 = (A-B)(A+B)$"
                )
            else:
                factored_num = sp.factor(num)
                factored_den = sp.factor(den)
                steps.append(
                    f"**ขั้นที่ 3: การแยกตัวประกอบ (Factorization)**\n"
                    f"ทำการแยกตัวประกอบของเศษและส่วน:\n"
                    f"$$\\frac{{{sp.latex(num)}}}{{{sp.latex(den)}}} = \\frac{{{sp.latex(factored_num)}}}{{{sp.latex(factored_den)}}}$$"
                )

            # ทำการตัดทอนตัวร่วม
            simplified_expr = sp.cancel(expr)
            steps.append(
                f"**ขั้นที่ 4: การตัดทอนตัวประกอบร่วม (Cancellation)**\n"
                f"เมื่อ $x \\neq {sp.latex(a_sym)}$ เราสามารถตัดทอนพจน์ร่วม $(x - {sp.latex(a_sym)})$ ออกได้:\n"
                f"$$g(x) = {sp.latex(simplified_expr)}$$"
            )

            # แทนค่าซ้ำในนิพจน์ที่ลดรูปแล้ว
            final_res = sp.simplify(simplified_expr.subs(X, a_sym))
            steps.append(
                f"**ขั้นที่ 5: การแทนค่าหลังตัดทอน (Final Evaluation)**\n"
                f"แทนค่า $x = {sp.latex(a_sym)}$ ลงในฟังก์ชันที่ลดรูปแล้ว:\n"
                f"$$\\lim_{{x \\to {sp.latex(a_sym)}}} f(x) = g({sp.latex(a_sym)}) = {sp.latex(final_res)}$$"
            )

            return {
                "ok": True,
                "result": float(final_res.evalf()),
                "latex": f"\\lim_{{x \\to {sp.latex(a_sym)}}} {sp.latex(expr)} = {sp.latex(final_res)}",
                "steps": steps,
                "expr": expr,
                "error": None,
            }
        elif val_den != 0:
            # กรณีแทนค่าได้ทันที
            final_res = sp.simplify(val_num / val_den)
            steps.append(
                f"**สรุปผลการคำนวณ:**\n"
                f"เนื่องจากตัวส่วนไม่เป็นศูนย์ ลิมิตมีค่าเท่ากับการแทนค่าตรง:\n"
                f"$$\\lim_{{x \\to {sp.latex(a_sym)}}} f(x) = {sp.latex(final_res)}$$"
            )
            return {
                "ok": True,
                "result": float(final_res.evalf()),
                "latex": f"\\lim_{{x \\to {sp.latex(a_sym)}}} {sp.latex(expr)} = {sp.latex(final_res)}",
                "steps": steps,
                "expr": expr,
                "error": None,
            }
        else:
            return {
                "ok": False,
                "result": None,
                "latex": "",
                "steps": steps,
                "expr": expr,
                "error": f"ตัวส่วนเป็นศูนย์แต่ตัวเศษไม่เป็นศูนย์ ลิมิตหาค่าไม่ได้ (เกิดเส้นกำกับแนวดิ่งที่ x = {a})",
            }

    except Exception as e:
        return {
            "ok": False,
            "result": None,
            "latex": "",
            "steps": [],
            "expr": None,
            "error": f"เกิดข้อผิดพลาดในการคำนวณ: {e}",
        }

4. ขั้นตอนวิธีทางคณิตศาสตร์: เส้นสัมผัสโค้งและอนุพันธ์ utils/tangent_solver.py

นิสิตส่วนใหญ่มักจำสูตรการดิฟลัดได้ (เช่น $\frac{d}{dx}x^2 = 2x$) แต่มักขาดมโนทัศน์ว่า "อนุพันธ์คือความชันของเส้นสัมผัสเส้นโค้งที่ได้จากการลู่เข้าของเส้นตัดโค้ง (Secant Line)" โมดูลนี้จึงต้องสร้างกระบวนการคำนวณ 2 ระดับ:

กระบวนการทางคณิตศาสตร์ (Algorithmic Logic):

  1. การคำนวณพิกัดจุดสัมผัส $(a, f(a))$:
    แทนค่า $x = a$ เพื่อหาพิกัดจุดสัมผัสบนกราฟ $y_0 = f(a)$
  2. การแสดงอัตราส่วนผลต่าง (Difference Quotient Formulation):
    สร้างนิพจน์ตามนิยามลิมิตของอนุพันธ์: $$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$ แสดงให้เห็นการกระจายพจน์ $f(a+h)$ และการลบด้วย $f(a)$ ซึ่งจะทำให้พจน์คงตัวหักล้างกันไป เหลือเพียงพจน์ที่มี $h$ เป็นตัวร่วม
  3. การตัดทอนตัวแปร $h$ และคำนวณความชัน $m$:
    ดึงตัวร่วม $h$ ออกจากตัวเศษ แล้วตัดทอนกับ $h$ ในตัวส่วน จากนั้นเทคลิมิต $h \to 0$ เพื่อหาค่าความชันที่แท้จริง $m = f'(a)$
  4. การหาสมการเส้นสัมผัส (Point-Slope Form):
    นำความชัน $m$ และพิกัดจุด $(a, y_0)$ เข้าสู่รูปสมการเส้นตรง: $$y - y_0 = m(x - a) \implies y = mx - ma + y_0$$

โครงร่างฟังก์ชันหลักใน utils/tangent_solver.py:

# utils/tangent_solver.py
H = sp.Symbol("h")

def compute_tangent(expr_str: str, a: float) -> dict[str, Any]:
    """คำนวณความชันและสมการเส้นสัมผัสโค้งตามนิยามลิมิตทีละขั้น"""
    try:
        expr = _parse_input(expr_str)
        a_sym = sp.Rational(str(a)).limit_denominator(1000)
        steps = []

        # 1. หาพิกัด y_0
        y0 = expr.subs(X, a_sym)
        steps.append(f"**ขั้นที่ 1: คำนวณพิกัดจุดบนเส้นโค้งที่ $x = {sp.latex(a_sym)}$**\n"
                     f"แทนค่า $x$ ในสมการ $f(x)$ จะได้จุดสัมผัส $(x_0, y_0) = ({sp.latex(a_sym)}, {sp.latex(y0)})$")

        # 2. ตั้งนิยามอนุพันธ์
        f_a_plus_h = expr.subs(X, a_sym + H)
        diff_quotient = (f_a_plus_h - y0) / H
        steps.append(f"**ขั้นที่ 2: ตั้งสมการตามนิยามความชันของเส้นสัมผัส**\n"
                     f"$$m = \\lim_{{h \\to 0}} \\frac{{f({sp.latex(a_sym)} + h) - f({sp.latex(a_sym)})}}{{h}} = \\lim_{{h \\to 0}} \\frac{{{sp.latex(sp.expand(f_a_plus_h))} - ({sp.latex(y0)})}}{{h}}$$")

        # 3. ตัดทอน h และเทคลิมิต
        diff_simplified = sp.cancel(diff_quotient)
        slope = sp.limit(diff_quotient, H, 0)
        steps.append(f"**ขั้นที่ 3: ตัดทอนพจน์ $h$ และเทคลิมิตเข้าสู่ 0**\n"
                     f"$$m = \\lim_{{h \\to 0}} ({sp.latex(diff_simplified)}) = {sp.latex(slope)}$$")

        # 4. หาสมการเส้นสัมผัส
        tangent_line = sp.simplify(slope * (X - a_sym) + y0)
        steps.append(f"**ขั้นที่ 4: หาสมการเส้นสัมผัสในรูป $y - y_0 = m(x - x_0)$**\n"
                     f"$$y - ({sp.latex(y0)}) = {sp.latex(slope)}(x - {sp.latex(a_sym)}) \\implies y = {sp.latex(tangent_line)}$$")

        return {
            "ok": True,
            "result": float(slope.evalf()),
            "latex": f"y = {sp.latex(tangent_line)}",
            "steps": steps,
            "expr": expr,
            "error": None,
        }
    except Exception as e:
        return {"ok": False, "result": None, "latex": "", "steps": [], "expr": None, "error": str(e)}

5. ขั้นตอนวิธีทางคณิตศาสตร์: ผลรวมรีมันน์และการลู่เข้าสู่ปริพันธ์ utils/riemann_solver.py

โมดูล utils/riemann_solver.py เป็นโมดูลที่พัฒนาเสร็จสมบูรณ์ 100% แล้วในคลังโค้ดปัจจุบัน และถือเป็น "ต้นแบบสมบูรณ์แบบ (Golden Standard)" ที่นิสิตต้องศึกษาเป็นตัวอย่าง

สูตรทางคณิตศาสตร์ทั้ง 3 วิธี:

วิธีการแบ่งช่วง (Method) สัญลักษณ์ จุดตัวแทนในแต่ละช่วงย่อย ($x_i^*$) สูตรผลรวมรีมันน์
จุดซ้าย (Left Endpoint) $L_n$ $x_i = a + i\Delta x$ $$L_n = \sum_{i=0}^{n-1} f(x_i)\Delta x$$
จุดขวา (Right Endpoint) $R_n$ $x_i = a + (i+1)\Delta x$ $$R_n = \sum_{i=1}^{n} f(x_i)\Delta x$$
จุดกึ่งกลาง (Midpoint) $M_n$ $\bar{x}_i = a + (i + 0.5)\Delta x$ $$M_n = \sum_{i=0}^{n-1} f(\bar{x}_i)\Delta x$$
จุดเชื่อมโยงเชิงมโนทัศน์ที่ต้องแสดงบน UI:
เมื่อผู้เรียนเลื่อน Slider ปรับค่าจำนวนช่วงย่อย $n$ จาก $4 \to 10 \to 50 \to 100$ ระบบจะต้องคำนวณค่าผลรวม $S_n$ ควบคู่ไปกับค่าปริพันธ์จำกัดเขตจริง $I = \int_a^b f(x)\,dx$ และแสดงค่าความคลาดเคลื่อน (Error = $|I - S_n|$) เพื่อให้นิสิตประจักษ์ด้วยสายตาว่า $\lim_{n \to \infty} S_n = \int_a^b f(x)\,dx$

6. ขั้นตอนวิธีทางคณิตศาสตร์: การอินทิเกรตด้วยการแทนค่าตัวแปร u utils/substitution_solver.py

การอินทิเกรตด้วยการเปลี่ยนตัวแปร $u$ (u-Substitution) เป็นหัวข้อที่ท้าทายที่สุดในการเขียนโค้ดอัตโนมัติ เนื่องจากคอมพิวเตอร์ทั่วไปจะอินทิเกรตรวดเดียว แต่ในการสอน เราต้องแยกแยะ 4 ขั้นตอน:

การแจกแจงขั้นตอนวิธีสำหรับโมดูล substitution_solver.py:

1. การเลือกฟังก์ชันภายใน $u = g(x)$ (Sub-expression Heuristic):
ใช้อัลกอริทึมค้นหาพจน์ย่อยที่อยู่ภายในวงเล็บยกกำลัง หรืออยู่ใต้เครื่องหมายกรณฑ์ เช่น ในนิพจน์ $2x(x^2 + 1)^3$ ระบบจะตรวจพบว่าฐาน $x^2 + 1$ คือตัวเลือกที่ดีที่สุดสำหรับกำหนดให้เป็น $u$

2. การหาอนุพันธ์และจัดรูปผลต่างเชิงอนุพันธ์ (Differential $du$):
คำนวณ $g'(x) = \frac{d}{dx}g(x)$ จากนั้นจัดรูปเพื่อแทนค่า $dx = \frac{du}{g'(x)}$

3. การแทนค่าลงในปริพันธ์และตัดทอนตัวแปร $x$ ให้หมดสิ้น:
นำ $u$ และ $dx$ ไปแทนค่าใน $\int f(x)\,dx$ แล้วทำการตัดทอนตัวแปร $x$ ด้วยคำสั่ง sp.simplify() หากยังมีตัวแปร $x$ หลงเหลืออยู่ แสดงว่าฟังก์ชันนี้ไม่เหมาะกับการใช้วิธีเปลี่ยนตัวแปร $u$ พื้นฐาน

4. การอินทิเกรตเทียบกับ $u$ และการแทนตัวแปรเดิมกลับ (Back Substitution):
ใช้สูตรเลขชี้กำลัง $\int u^n\,du = \frac{u^{n+1}}{n+1} + C$ จากนั้นแทน $u = g(x)$ กลับเข้าไปในคำตอบสุดท้าย

คำถามที่ 3: "จะพิสูจน์ทางวิชาการอย่างไรว่าแอปนี้ช่วยให้ผู้เรียนเข้าใจจริง?"

แนวคิดในการตอบ: นำเสนอระเบียบวิธีวิจัยแบบ Two-tier Evaluation (วัดความถูกต้องของระบบคู่กับผลสัมฤทธิ์ทางการเรียน)

สคริปต์ตอบ:
"ทางกลุ่มวางแผนการประเมินผลออกเป็น 2 มิติครับ มิติแรกคือ System & Mathematical Rigor โดยวัดความถูกต้องของขั้นตอนและผลเฉลยผ่านชุด Automated Test Cases ที่ครอบคลุมโจทย์มาตรฐานและ Edge Cases ทั้งหมด

และมิติที่สองคือ Pedagogical Effectiveness ซึ่งเราจะไม่ใช้เพียงแบบสอบถามความพึงพอใจทั่วไป แต่จะทำการทดสอบกับกลุ่มตัวอย่างนิสิตด้วย แบบทดสอบวัดมโนทัศน์ก่อนและหลังใช้งาน (Pre-test / Post-test) ในจุดที่มักเกิดข้อผิดพลาดซ้ำซาก เพื่อประเมินว่าระบบสามารถช่วยลดอัตราความเข้าใจผิดทางคณิตศาสตร์ได้อย่างมีนัยสำคัญหรือไม่ครับ"
