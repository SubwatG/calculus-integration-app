2. การลงลึกทางคณิตศาสตร์: สร้าง Step-by-Step Solvers อย่างไร? MATH ENGINE DEEP DIVE

ปัญหาคลาสสิกคือ ถ้าใช้คำสั่งอย่าง sp.limit(f, x, a) ของ SymPy มันจะพ่นคำตอบสุดท้ายออกมาทันที เช่น ได้ $4$ แต่นิสิตจะไม่เห็นกระบวนการคิด ดังนั้นเราต้องเขียน "Mathematical Deconstruction Algorithm" ดังนี้:

กรณีที่ 1: การหาลิมิต $\lim_{x \to a} f(x)$ ในรูปแบบยังไม่กำหนด $\frac{0}{0}$ (Indeterminate Form)

ในแคลคูลัส 1 นิสิตมักติดกับดักเมื่อแทนค่า $x = a$ แล้วตัวส่วนเป็นศูนย์ โมดูล utils/limit_solver.py ต้องดำเนินตาม 4 ขั้นตอนนี้:

  1. Direct Substitution Check: แทนค่า $x = a$ เข้าไปตรง ๆ ในเศษ $N(a)$ และส่วน $D(a)$ ถ้า $D(a) = 0$ และ $N(a) = 0$ ให้ติดป้ายว่าเกิดรูปแบบ $\left[\frac{0}{0}\right]$ ทันที
  2. Structural Branching (จำแนกรูปแบบสมการ):
    • กรณีพหุนาม (Rational): ดึงตัวประกอบ $(x - a)$ ออกจากทั้งเศษและส่วนด้วยคำสั่ง sp.factor() จากนั้นทำการตัดทอน (Cancel out) แล้วแทนค่า $a$ ใหม่อีกครั้ง
    • กรณีมีกรณฑ์ (Conjugate): ถ้าตรวจพบฟังก์ชันกรณฑ์ เช่น $\sqrt{g(x)} - c$ ให้หาสังยุคคือ $\sqrt{g(x)} + c$ นำมาคูณทั้งเศษและส่วน แล้วใช้ผลต่างกำลังสอง $A^2 - B^2$ เพื่อปลดราก
  3. Emitting Pedagogical Steps: บันทึกสมการในแต่ละบรรทัดลงในลิสต์ steps โดยเก็บเป็นข้อความ LaTeX ที่สมบูรณ์
# ตัวอย่างการเขียน Logic ใน utils/limit_solver.py def solve_indeterminate_limit(expr, a): steps = [] num, den = expr.as_numer_denom() # ขั้นที่ 1: ตรวจสอบ 0/0 val_num = num.subs(X, a) val_den = den.subs(X, a) if val_den == 0 and val_num == 0: steps.append(r"\text{เมื่อแทนค่า } x = %s \text{ พบว่าอยู่ในรูปแบบยังไม่กำหนด } \left[\frac{0}{0}\right]" % a) # ขั้นที่ 2: ตรวจหารูปแบบกรณฑ์เพื่อใช้สังยุค if any(arg.is_Pow and arg.exp == sp.Rational(1, 2) for arg in num.atoms()): steps.append(r"\text{สังเกตเห็นเครื่องหมายกรณฑ์ จึงนำสังยุคมาคูณทั้งเศษและส่วน}") # คำนวณสังยุคและแสดงรูปคูณ else: # แยกตัวประกอบพหุนาม factored_num = sp.factor(num) factored_den = sp.factor(den) steps.append(r"\text{แยกตัวประกอบ: } \frac{%s}{%s}" % (sp.latex(factored_num), sp.latex(factored_den))) simplified = sp.cancel(expr) steps.append(r"\text{ตัดทอนตัวประกอบร่วม }(x - %s)\text{ ได้: } %s" % (a, sp.latex(simplified))) final_ans = simplified.subs(X, a) steps.append(r"\text{แทนค่า } x = %s \text{ อีกครั้ง จะได้คำตอบเท่ากับ } %s" % (a, sp.latex(final_ans))) return {"ok": True, "result": float(final_ans), "steps": steps}

กรณีที่ 2: ผลรวมรีมันน์ (Riemann Sum) และการลู่เข้าสู่อินทิกรัล

ใน utils/riemann_solver.py ที่ทำเสร็จสมบูรณ์แล้ว ถือเป็น พิมพ์เขียวตัวอย่างชั้นดี ที่นิสิตต้องใช้เป็นแนวทางในบทอื่น ๆ:

  • คำนวณความกว้างของแต่ละช่วงย่อย: $\Delta x = \frac{b - a}{n}$
  • คำนวณพิกัดจุดตัวแทนตาม 3 วิธี:
    • จุดซ้าย: $x_i = a + i\Delta x$
    • จุดขวา: $x_i = a + (i+1)\Delta x$
    • จุดกึ่งกลาง: $\bar{x}_i = a + (i + 0.5)\Delta x$
  • นำความสูง $f(x_i)$ คูณกับ $\Delta x$ เพื่อหาพื้นที่แท่งสี่เหลี่ยมแต่ละแท่ง แล้วรวมกัน: $$\sum_{i=1}^n f(x_i^*) \Delta x$$
  • ความเชื่อมโยงระดับลึก: ในหน้าเว็บ นิสิตต้องแสดงให้เห็นว่า เมื่อเลื่อนแถบสไลเดอร์ให้ $n \to \infty$ ค่าผลรวมรีมันน์จะวิ่งเข้าหาค่าอินทิกรัลจำกัดเขต $\int_a^b f(x)\,dx$ พอดี นี่คือจุดที่ทำให้เกิดมโนทัศน์ ไม่ใช่แค่ดูสูตร
3. สถานะปัจจุบันและสิ่งที่ต้องลงรายละเอียดให้ลึก PROJECT ROADMAP

ตารางสรุปสถานะของโค้ดในโปรเจกต์ปัจจุบัน สิ่งที่เสร็จแล้ว และสิ่งที่เป็นโครงเปล่า (Skeleton) ที่ต้องลงมือเขียน:

หัวข้อบทเรียน ไฟล์ Solver สถานะ สิ่งที่ต้องลงลึก / จุดวิกฤติทางคณิตศาสตร์
ผลรวมรีมันน์ (Riemann Sum) riemann_solver.py สมบูรณ์ 100% ใช้เป็นต้นแบบ (Blueprint) ให้กับบทอื่น ๆ ทั้งการคืน Dict และการเขียน Test
ลิมิตเข้าใกล้จุด (Limits) limit_solver.py Skeleton รอเติม เขียน Rule-based แตกกรณีพหุนาม vs กรณฑ์สังยุค สำหรับรูปแบบ $0/0$
เส้นสัมผัสและอนุพันธ์ (Tangent) tangent_solver.py Skeleton รอเติม แสดงนิยาม $f'(a) = \lim_{h\to 0}\frac{f(a+h)-f(a)}{h}$ และหาสมการเส้นตรง $y - y_1 = m(x - x_1)$
การอินทิเกรตด้วยการแทนค่า (u-sub) substitution_solver.py Skeleton รอเติม ยากที่สุด: ต้องมีขั้นตอนสมมติตัวแปร $u = g(x)$, หา $du = g'(x)dx$, และแทนค่ากลับ
พื้นที่ระหว่างเส้นโค้ง (Area Between) area_solver.py Skeleton รอเติม ต้องคำนวณจุดตัดของกราฟ 2 เส้น และแยกช่วงว่ากราฟไหนอยู่บน/ล่าง: $\int (f - g)dx$
ข้อแนะนำเชิงกลยุทธ์สำหรับอาจารย์และนิสิต:
สำหรับการสอบจบและทำรูปเล่ม ไม่จำเป็นต้องทำครบทั้ง 6 หัวข้อ หากเวลาจำกัด ให้ล็อกเป้าไว้ที่ 3 หัวข้อหลักแรกเท่านั้น (Riemann + Limit + Tangent) แต่ทำระบบแจกแจงขั้นตอน (Step-by-step) ให้ลึก แม่นยำ และมี Pytest ครอบคลุมสมบูรณ์ ดีกว่าเปิดหลายหัวข้อแล้วด้านในกลวงหรือพังง่าย
