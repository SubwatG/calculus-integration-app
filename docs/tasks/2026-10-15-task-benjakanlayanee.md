งานของเบญจกัลยาณีในรอบนี้คือการขับเคลื่อน **การประเมินผลผู้ใช้งานจริง (User Evaluation) และการเก็บความเรียบร้อยของระบบ** ใน 2 จุดสำคัญ:

2. ปรับปรุงข้อมูลใน **หน้าช่วยเหลือ (`pages/help.py`)** และ **หน้าประวัติคะแนน (`pages/history.py`)** ให้ครบถ้วนสมบูรณ์

## 📋 รายละเอียดงานที่ต้องดำเนินการ (Task Breakdown)

### ภารกิจที่ 1: จัดทำ Google Forms และเชื่อมโยงหน้าแบบประเมิน (`pages/survey.py`)
1. **จัดทำแบบสอบถามออนไลน์ (Google Forms):**
   - เปิดอ่านไฟล์ `docs/calculus-app-satisfaction-survey.qmd` ในโฟลเดอร์ของโปรเจกต์ ซึ่งมีเนื้อหาแบบสอบถาม 4 ตอนสมบูรณ์:
     - **ตอนที่ 1:** ข้อมูลทั่วไปของผู้ตอบแบบประเมิน (ระดับชั้น, ประสบการณ์เรียนแคลคูลัส, อุปกรณ์ที่ใช้)
     - **ตอนที่ 2:** ความพึงพอใจต่อคุณลักษณะของระบบ 4 ด้าน (UI/UX, ฟังก์ชันและการคำนวณ, เนื้อหาและมโนทัศน์, เจตคติและแรงจูงใจ) รวม 20 ข้อ (มาตรวัด 1–5)
     - **ตอนที่ 3:** แบบวัดความสะดวกในการใช้งานตามมาตรฐานสากล (System Usability Scale: SUS 10 ข้อ)
     - **ตอนที่ 4:** ข้อเสนอแนะเพิ่มเติมสำหรับการพัฒนา
   - นำคำถามดังกล่าวไปสร้างใน **Google Forms** ภายใต้บัญชี Google ของนิสิต/โครงการ
2. **เชื่อมโยง URL และ QR Code ในแอป:**
   - คัดลอก URL ของ Google Forms ฉบับจริงมาใส่ใน `st.link_button` ที่หน้า `pages/survey.py`
   - สร้างภาพ QR Code ที่ชี้ไปยัง URL ฟอร์มจริง แล้วบันทึกไฟล์ทับที่ `docs/calculus-survey-qr.png`
   - ยืนยันว่าเมื่อผู้ใช้เปิดหน้า `pages/survey.py` ในแอป สามารถสแกนหรือกดปุ่มเพื่อเข้าทำแบบสอบถามจริงได้ทันที

### ภารกิจที่ 2: ปรับปรุงหน้าช่วยเหลือและหน้าประวัติคะแนน
1. **อัปเดตข้อความในหน้าช่วยเหลือ (`pages/help.py`):**
   - ในหัวข้อ *"ข้อจำกัด"* (บริเวณบรรทัดที่ 32) ยังมีข้อความเก่าระบุว่า:
     *"เครื่องมือคำนวณด้วย SymPy ยังเป็นโครงร่างการคำนวณเบื้องต้น สามารถคำนวณและระบุขั้นตอนกฎกำลังได้สำหรับพจน์ monomial"*
   - ให้อัปเดตข้อความให้ตรงกับความจริงของระบบในปัจจุบัน:
     อธิบายว่าปัจจุบันระบบรองรับการคำนวณสัญลักษณ์ครอบคลุมทั้ง การหาอนุพันธ์และสมการเส้นสัมผัส, ลิมิตเข้าใกล้จุดและรูปแบบไม่กำหนด, ผลรวมรีมันน์ 3 วิธี, การอินทิเกรตโดยการแทนค่า ($u$-sub) และ By Parts, พื้นที่ระหว่างเส้นโค้ง, ปริพันธ์ไม่ตรงแบบช่วงอนันต์, และปริมาตรทรงตันจากการหมุน
2. **ขยายการแมปชื่อหัวข้อภาษาไทยในหน้าประวัติคะแนน (`pages/history.py`):**
   - ปัจจุบันพจนานุกรม `topic_titles` แมปไว้เฉพาะ `"basic_rules"` เพียงอย่างเดียว
   - ให้เพิ่มการแมปชื่อภาษาไทยให้ครอบคลุมทุกหมวดแบบทดสอบใหม่ที่ได้พัฒนาขึ้น:
     - `"riemann"`: `"ผลรวมรีมันน์และการประมาณค่า"`
     - `"techniques"`: `"เทคนิคการอินทิเกรต (u-Sub และ By Parts)"`
     - `"limits"`: `"ลิมิตและความต่อเนื่อง"`
     - `"tangent"`: `"เส้นสัมผัสและอนุพันธ์"`
     - `"area_between"`: `"พื้นที่ระหว่างเส้นโค้ง"`
     - `"improper_integrals"`: `"ปริพันธ์ไม่ตรงแบบ"`
     - `"volume_revolution"`: `"ปริมาตรของรูปทรงตัน"`
     - `"all"`: `"รวมทุกมโนทัศน์ (Comprehensive)"`

## 🧪 ขั้นตอนการทดสอบและเกณฑ์การส่งมอบ (Verification & DoD)
1. ดึงโค้ดล่าสุดก่อนเริ่มงาน:
   ```bash
   git checkout main
   git pull origin main
   git checkout -b feat/survey-integration-and-ui-polish
   ```
2. รันชุดทดสอบทั้งหมด:
   ```bash
   pytest tests/
   ```
   **เกณฑ์สำเร็จ:** ชุดทดสอบทั้งหมด 126+ ข้อต้องผ่านครบ 100% (All Green)
3. ตรวจสอบการทำงานของหน้าเว็บ:
   ```bash
   streamlit run app.py
   ```
   - เปิดหน้า **"แบบประเมินความพึงพอใจ (SUS)"** ทดสอบคลิกลิงก์ Google Forms และตรวจดูความคมชัดของภาพ QR Code
   - เปิดหน้า **"ประวัติคะแนนในเซสชัน"** ทดลองทำแบบทดสอบ 1 ชุด แล้วตรวจดูว่าตารางแสดงชื่อหัวข้อภาษาไทยถูกต้อง
   - เปิดหน้า **"คู่มือการใช้งานและโครงงาน"** ยืนยันว่าข้อความอธิบายถูกต้องทันสมัย
4. Commit และ Push ขึ้น GitHub:
   ```bash
   git add pages/survey.py docs/calculus-survey-qr.png pages/help.py pages/history.py
   git commit -m "feat(survey): wire production Google Forms, update help content and quiz topic mappings"
   git push origin feat/survey-integration-and-ui-polish
   ```
