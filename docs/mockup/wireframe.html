วิธีทำโจทย์ตัวอย่าง (6 ข้อ)

ตัวอย่างที่ 1 · ปริพันธ์ (กฎกำลัง)
จงหา ∫ 3x² dx
1) เขียนอินทิกรัล : ∫ 3x² dx
2) ดึงค่าคงที่ออก : 3 ∫ x² dx
3) ใช้กฎกำลัง ∫ xn dx = xn+1/(n+1) + C โดย n = 2 :
∫ x² dx = x³/3 + C
4) คูณกลับค่าคงที่ : 3 · x³/3 + C = x³ + C
คำตอบ : ∫ 3x² dx = x³ + C
ตัวอย่างที่ 2 · ปริพันธ์ (กฎกำลัง)
จงหา ∫ x⁴ dx
1) ใช้กฎกำลัง โดย n = 4 : ∫ x⁴ dx = x⁵/5 + C
คำตอบ : ∫ x⁴ dx = x⁵/5 + C
ตัวอย่างที่ 3 · ปริพันธ์ (กฎผลบวก)
จงหา ∫ (2x + 7) dx
1) แยกผลบวก : ∫ (2x + 7) dx = ∫ 2x dx + ∫ 7 dx
2) ∫ 2x dx = 2 · x²/2 + C = x² + C
3) ∫ 7 dx = 7x + C
4) รวมผลลัพธ์ : x² + 7x + C
คำตอบ : ∫ (2x + 7) dx = x² + 7x + C
ตัวอย่างที่ 4 · ปริพันธ์ (ฟังก์ชัน 1/x)
จงหา ∫ (1/x) dx
1) ใช้สูตร ∫ (1/x) dx = ln|x| + C
คำตอบ : ∫ (1/x) dx = ln|x| + C
ตัวอย่างที่ 5 · อนุพันธ์ (กฎกำลัง)
จงหา d/dx (x³)
1) ใช้กฎกำลัง d/dx (xn) = n·xn−1 โดย n = 3
2) d/dx (x³) = 3x²
คำตอบ : d/dx (x³) = 3x²
ตัวอย่างที่ 6 · ลิมิต (แยกตัวประกอบ)
จงหา limx→2 (x² − 4)/(x − 2)
1) แทนค่า x = 2 ตรงๆ ได้ 0/0 → รูปแบบไม่กำหนด
2) แยกตัวประกอบตัวเศษ : x² − 4 = (x − 2)(x + 2)
3) ตัดทอน (เมื่อ x ≠ 2) : (x − 2)(x + 2)/(x − 2) = x + 2
4) แทนค่า x = 2 : 2 + 2 = 4
คำตอบ : limx→2 (x² − 4)/(x − 2) = 4
