# Mockup — Calculus Tutor Web App (โครงร่าง)

Mockup HTML โครงร่างสำหรับโครงงาน "เว็บแอปพลิเคชันช่วยเรียนคณิตศาสตร์สำหรับแคลคูลัสเบื้องต้น"
สร้างขึ้นจากไฟล์ `(ร่าง) ออกแบบหน้าเว็บ.pdf` ของนักศึกษา (โครงร่าง 6 หน้า)

## ไฟล์ในโฟลเดอร์

- `index.html` — mockup แบบมีสี/ธีม (หน้าตาใกล้เคียงเวอร์ชันจริง ตามร่างนักศึกษา)
- `wireframe.html` — **wireframe แท้**: ขาวดำ ไม่มีสีพื้นหลัง ดีไซน์น้อยที่สุด
  เนื้อหาเหลือแค่สมการ + วิธีทำโจทย์ตัวอย่าง 6 ข้อ (ส่วนอื่นเป็นกล่องเส้นประ placeholder)
  เหมาะสำหรับเอาไปใช้ในรายงานโครงงาน หรือคุยกับนักศึกษาเรื่องโครงสร้างก่อนทำจริง

## วิธีเปิด

เปิดไฟล์ `index.html` หรือ `wireframe.html` ด้วยเบราว์เซอร์ใดก็ได้ (ไม่ต้องมีเซิร์ฟเวอร์):

```
xdg-open index.html
```

## หน้าจอใน mockup

| หน้าจอ | รายละเอียด | อ้างอิงจากร่าง |
|---|---|---|
| หน้าหลัก | แบนเนอร์หัวเว็บ + ช่องค้นหา + การ์ดเมนู | หน้า 1 ของร่าง |
| บทเรียน | หัวข้อบท (ค่าจำกัดข้างเดียวและแคลคูลัส) + เนื้อหาตัวยึด (skeleton) | หน้า 2–3 ของร่าง |
| แก้โจทย์ | เลือกเนื้อหา + ใส่โจทย์ + แถบสูตรสำเร็จรูป + วิธีทำแบบพับเก็บได้ | หน้า 4 ของร่าง |
| เลือกหัวข้อ | ปุ่มวงกลมเลือกหัวข้อหลัก + ระดับโจทย์ | หน้า 5 ของร่าง |
| เกมทบทวน | กล่องคำถาม + กริดคำตอบ 2×2 พร้อม feedback ✓/✗ | หน้า 6 ของร่าง |
| ประวัติที่ทำ / ช่วยเหลือ | หน้าว่าง placeholder | เมนูในร่าง |

## โทนสีที่ใช้ (จากร่างของนักศึกษา)

- Sidebar: ลาเวนเดอร์อ่อน (`#b9bce8 → #d3d5f5`)
- พื้นหลัง: ฟ้าอ่อนพาสเทล (`#eaf1ff`)
- ตัวหนังสือ: น้ำเงินเข้ม/indigo (`#232a4d`)
- การ์ด/ปุ่ม: ฟ้าอ่อน-ม่วงอ่อน ตามที่ร่างไว้
- ฟอนต์: Chakra Petch (รองรับภาษาไทย) — ตามความนิยมของอาจารย์

## สิ่งที่ยังไม่ทำ (ตั้งใจ)

- เนื้อหาบทเรียนเป็นตัวยึด (skeleton/shimmer) — ยังไม่ใส่เนื้อหาจริง
- ปุ่มคำนวณในหน้าแก้โจทย์แสดงผลลัพธ์ตัวอย่างเท่านั้น ยังไม่ได้ต่อ SymPy
- โจทย์เกมเป็นตัวอย่าง 3 ข้อ ยังไม่ใช่คลังข้อสอบจริง
- ยังไม่ responsive เต็มรูปแบบสำหรับมือถือ (มี breakpoint พื้นฐาน)

## ขั้นตอนต่อไป (ข้อเสนอ)

1. เอา mockup นี้ไปให้อาจารย์/นักศึกษาดู เพื่อ confirm โครงสร้างและโทนสี
2. เมื่อโครงสร้าง OK → เริ่มสร้างหน้า Streamlit จริง (`Home`, `Lessons`, `Solver`, `Quiz`)
3. ต่อ SymPy engine สำหรับการคำนวณจริงในหน้าแก้โจทย์
4. ใส่เนื้อหาบทเรียนจริงจาก `reference/calculus2-books/`
