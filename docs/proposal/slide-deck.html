1. Conditions ⚠️

เงื่อนไขการใช้สูตร เช่น $f(x)$ ต้องมีความต่อเนื่องบนช่วงปิด $[a,b]$ หรือเงื่อนไข $f(x) \ge 0$

2. Formulas 📐

สูตร นิยาม และทฤษฎีบทหลักในรูปสัญลักษณ์ LaTeX ที่ถูกต้องตามมาตรฐานสากล

3. Properties 🔍

สมบัติสำคัญ เช่น การลู่เข้าของผลรวมสู่ค่าปริพันธ์ หรือความสัมพันธ์ลิมิตซ้าย-ขวา

4. Misconceptions 🚫

ข้อควรระวัง เช่น การลืมคูณ $\Delta x$ ในผลรวม หรือการลืมใส่ค่าสัมบูรณ์เมื่อพื้นที่อยู่ใต้แกน $x$

5. Applications 🚀

การประยุกต์ใช้จริง เช่น การหาระยะทางจากการอินทิเกรตความเร็ว หรืองานในวิศวกรรม

6. Decision Guide 🧭

แนวทางการตัดสินใจเลือกใช้เทคนิคคำนวณให้เหมาะสมกับรูปแบบของฟังก์ชัน

3. วิธีการดำเนินการศึกษา • Mathematical Rigor
ขั้นตอนวิธีคณิตศาสตร์: กรณีศึกษาผลรวมรีมันน์ (Midpoint Riemann Sum)
08 / 20
🧮 ตรรกะการคำนวณ (Algorithm Logic)
  1. ความกว้างช่วงย่อย ($\Delta x$): $$\Delta x = \frac{b - a}{n}$$
  2. จุดตัวแทนกึ่งกลางแต่ละช่วง ($x_i$): $$x_i = a + (i + 0.5)\Delta x, \quad i = 0, 1, \dots, n-1$$
  3. ผลรวมพื้นที่สี่เหลี่ยมย่อย ($M_n$): $$M_n = \sum_{i=0}^{n-1} f(x_i)\Delta x$$
📊 ตัวอย่างการทำงานจริง ($f(x)=x^2$ บน $[0,2]$, $n=8$)
  • $\Delta x = \frac{2-0}{8} = 0.25$
  • เซตจุดตัวแทน: $\{0.125, 0.375, 0.625, 0.875, \dots, 1.875\}$
  • ผลรวมประมาณค่า: $M_8 = \sum f(x_i)(0.25) \approx \mathbf{2.65625}$
  • การเปรียบเทียบกับค่าจริงด้วย SymPy CAS: $$\int_0^2 x^2 \, dx = \left[ \frac{x^3}{3} \right]_0^2 = \frac{8}{3} \approx \mathbf{2.66667}$$
  • $\text{Error} = |2.66667 - 2.65625| = 0.01042$ (แสดงการลู่เข้าชัดเจน)

🧩 ตัวอย่างโจทย์: $\int x e^x \, dx$
Step 1: การใช้ Decision Guide (LIATE Rule)
• ผู้เรียนเปรียบเทียบระหว่าง $x$ (Algebraic) และ $e^x$ (Exponential)
• ระบบแนะนำ: ให้ $u = x \implies du = dx$ และ $dv = e^x dx \implies v = e^x$

Step 2: แทนค่าลงในสูตร
$$\int x e^x \, dx = x e^x - \int e^x \, dx$$
Step 3: อินทิเกรตพจน์ที่เหลือและสรุปคำตอบ
$$= x e^x - e^x + C = (x-1)e^x + C$$
💡 กลไกของเว็บแอปพลิเคชันที่สอดคล้องกับโครงงาน
  • Scaffolding Step-by-Step: ระบบไม่แสดงคำตอบ $(x-1)e^x$ ในทันที แต่มีปุ่มกด 'ตรวจสอบการเลือก u' และ 'แสดงขั้นตอนการหา v' ทีละขั้น
  • Misconception Alert: แจ้งเตือนกรณีผู้เรียนสลับเลือก $u = e^x, dv = x dx$ ซึ่งจะทำให้พจน์อินทิเกรตซับซ้อนขึ้นเป็น $\int \frac{x^2}{2} e^x dx$
  • SymPy Verification: ระบบใช้ SymPy คำนวณ Derivative กลับเพื่อพิสูจน์ $\frac{d}{dx}[(x-1)e^x] = x e^x$ ยืนยันความถูกต้อง 100%
