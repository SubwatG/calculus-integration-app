## 1. ที่มาและปัญหาในระบบเดิม (Problem Statement)

ในระบบปัจจุบันของ `utils/limit_solver.py`:
เมื่อผู้ใช้หรือนักศึกษาป้อนโจทย์ลิมิตเข้าใกล้จุดจำกัด เช่น:
$$\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$$
ระบบจะแสดงขั้นตอนการเฉลยดังนี้:
1. กำหนดโจทย์ $\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$
2. พิจารณาลิมิตทางซ้าย $\lim_{x \to 2^-} f(x) = 4$
3. พิจารณาลิมิตทางขวา $\lim_{x \to 2^+} f(x) = 4$
4. เปรียบเทียบลิมิตสองด้าน: เนื่องจากลิมิตซ้าย $=$ ลิมิตขวา $= 4$ ดังนั้นลิมิตสองด้านมีค่าเท่ากับ $4$

### ข้อบกพร่องเชิงการสอน (Pedagogical Defects):
1. **แข็งทื่อเกินไป (Overly Formal/Rigid):** ฟังก์ชันตรรกยะทั่วไปทั้งฝั่งซ้ายและฝั่งขวามีสูตรเดียวกัน การบังคับแยก $x \to 2^-$ กับ $x \to 2^+$ จึงผิดธรรมชาติและไม่ได้สะท้อนวิธีคำนวณจริง
2. **ข้ามหัวใจสำคัญของแคลคูลัส (Missing $0/0$ & Factoring):** ไม่มีการแสดงว่าเมื่อแทนค่าตรงแล้วเจอ $\frac{0}{0}$ (รูปแบบยังไม่กำหนด) และไม่มีการแสดงการแยกตัวประกอบ $\frac{(x-2)(x+2)}{x-2}$ รวมถึงการตัดทอนตัวร่วม
3. **นศ. ไม่เห็นที่มาของตัวเลข:** ผลลัพธ์ $4$ ในลิมิตซ้าย-ขวาเสกมาจาก SymPy โดยตรง นศ. ไม่เข้าใจว่าตัวเลขดังกล่าวคำนวณมาอย่างไร

## 2. โครงสร้างการตัดสินใจและจัดหมวดหมู่โจทย์ (Decision Architecture)

ลำดับการตัดสินใจ (Decision Hierarchy) ในการแก้และเฉลยโจทย์ลิมิต:

```text
[ป้อนโจทย์ lim_{x -> a} f(x)]
         │
         ├─── กรณีที่ 1: x -> ±∞ ─────────────► [End Behavior / เส้นกำกับแนวนอน] (คงเดิม)
         │
         ├─── กรณีที่ 2: มีเงื่อนไขแบ่งฝั่งชัดเจน ──► [Two-Sided Analysis] (แยกซ้าย vs ขวา)
         │    (มี Abs(x-a), Piecewise, รอยกระโดด)
         │
         ├─── กรณีที่ 3: แทนค่า x = a ได้ตรงๆ ─────► [Direct Substitution]
         │    (พหุนาม, ฟังก์ชันต่อเนื่อง ณ จุดนั้น)   f(a) เป็นจำนวนจริง -> จบขั้นตอน
         │
         ├─── กรณีที่ 4: แทนค่าแล้วได้ 0/0 ───────► [Indeterminate Form 0/0]
         │    (Indeterminate Form)                   ├─ 4.1: แยกตัวประกอบ & ตัดทอน (Factoring)
         │                                           ├─ 4.2: คูณสังยุค (Conjugate)
         │                                           └─ 4.3: ลิมิตตรีโกณมิติพื้นฐาน (sin x / x -> 1)
         │
         ├─── กรณีที่ 5: ส่วนเป็น 0 แต่เศษไม่ใช่ 0 ──► [Infinite Limits / Asymptotes]
         │    (รูป c / 0 เมื่อ c ≠ 0)                วิเคราะห์เครื่องหมายตัวส่วนฝั่งซ้าย/ขวา -> ±∞
         │
         └─── กรณีที่ 6: แกว่งกวัด / นอกโดเมน ────► [Oscillating / Domain Boundary] (คงเดิม)
```

## 3. รายละเอียดขั้นตอนการเฉลยในแต่ละกลุ่ม (Step Generation Details)

### กลุ่มที่ 1: การแทนค่าโดยตรง (Direct Substitution Property)
- **ตัวอย่าง:** $\lim_{x \to 2} (3x + 1)$ หรือ $\lim_{x \to 0} \cos(x)$
- **ขั้นตอน:**
  1. ระบุโจทย์และการสังเกต: ฟังก์ชันต่อเนื่องที่จุด $x = a$
  2. แสดงการแทนค่าโดยตรง: $f(a) = \dots$
  3. สรุปผลลัพธ์ $\lim_{x \to a} f(x) = f(a) = L$

### กลุ่มที่ 2: รูปแบบยังไม่กำหนด $\frac{0}{0}$ (Indeterminate Form)
- **ตัวอย่าง:** $\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$
- **ขั้นตอน:**
  1. ตรวจสอบการแทนค่าเบื้องต้น: $f(2) = \frac{0}{0}$ (รูปแบบยังไม่กำหนด) จึงยังสรุปค่าไม่ได้
  2. การจัดรูปพีชคณิต: แยกตัวประกอบตัวเศษ $x^2 - 4 = (x-2)(x+2)$
  3. การตัดทอนตัวร่วม: ชี้แจงเหตุผลสำคัญว่า *"เพราะ $x \to 2$ หมายถึง $x \neq 2$ ทำให้ $x - 2 \neq 0$ จึงตัดทอนได้"* เหลือ $x + 2$
  4. หาลิมิตของฟังก์ชันที่ตัดทอนแล้ว: $\lim_{x \to 2} (x + 2) = 2 + 2 = 4$
  5. สรุปผล $\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = 4$

### กลุ่มที่ 3: ลิมิตตรีโกณมิติพื้นฐาน (Special Trigonometric Limit)
- **ตัวอย่าง:** $\lim_{x \to 0} \frac{\sin(x)}{x}$
- **ขั้นตอน:**
  1. ตรวจสอบการแทนค่าตรง: ได้ $\frac{0}{0}$
  2. ระบุทฤษฎีบทลิมิตสำคัญของฟังก์ชันตรีโกณมิติ (Fundamental Trigonometric Limit): $\lim_{x \to 0} \frac{\sin x}{x} = 1$ (อิงจาก Squeeze Theorem)
  3. สรุปผลค่าลิมิต $= 1$

### กลุ่มที่ 4: ลิมิตอนันต์และเส้นกำกับแนวดิ่ง (Infinite Limit $\frac{c}{0}$)
- **ตัวอย่าง:** $\lim_{x \to 0} \frac{1}{x}$ หรือ $\lim_{x \to 0} \frac{1}{x^2}$
- **ขั้นตอน:**
  1. ตรวจสอบการแทนค่า: ตัวเศษมีค่าคงที่ $c \neq 0$ ขณะที่ตัวส่วนลู่เข้าสู่ $0$ ทำให้ค่าฟังก์ชันพุ่งสู่อนันต์
  2. พิจารณาเครื่องหมายฝั่งซ้าย: เครื่องหมายของตัวส่วนเมื่อ $x \to a^-$ ส่งผลให้ $f(x) \to \pm\infty$
  3. พิจารณาเครื่องหมายฝั่งขวา: เครื่องหมายของตัวส่วนเมื่อ $x \to a^+$ ส่งผลให้ $f(x) \to \pm\infty$
  4. เปรียบเทียบและสรุปผล: หากเครื่องหมายเหมือนกันลู่ไปอนันต์เดียวกัน หรือหากเครื่องหมายต่างกันให้สรุปว่าไม่มีลิมิต (DNE)

### กลุ่มที่ 5: ฟังก์ชันแบ่งช่วงและค่าสัมบูรณ์ (Piecewise / Absolute Value)
- **ตัวอย่าง:** $\lim_{x \to 0} \frac{|x|}{x}$
- **ขั้นตอน:**
  1. ชี้แจงเหตุผลที่ต้องแยกสองด้าน: เนื่องจากมีพจน์ค่าสัมบูรณ์หรือการแบ่งช่วงที่มีนิยามต่างกันสองฝั่ง
  2. ลิมิตทางซ้าย ($x < a$): ปลดค่าสัมบูรณ์เป็น $-(x-a)$ แล้วคำนวณ
  3. ลิมิตทางขวา ($x > a$): ปลดค่าสัมบูรณ์เป็น $(x-a)$ แล้วคำนวณ
  4. สรุปผลตามทฤษฎีบทลิมิตสองด้าน: เท่ากันสรุปมีลิมิต ไม่เท่ากันสรุป DNE

## 6. การครอบคลุมรูปแบบไม่กำหนดทั้ง 7 แบบ (The 7 Indeterminate Forms & Determinate Forms)

ในทางคณิตศาสตร์ รูปแบบยังไม่กำหนด (Indeterminate Forms) ไม่ได้จำกัดอยู่เพียง $\frac{0}{0}$ เท่านั้น แต่มีทั้งหมด 7 รูปแบบมาตรฐานที่ต้องสอนให้นิสิตเข้าใจความแตกต่างกับการสรุปค่าได้ทันที (Determinate Forms):

### 6.1 รูปแบบยังไม่กำหนดทั้ง 7 รูปแบบ (Indeterminate Forms)
1. **รูปผลหาร (Quotient):**
   - $\frac{0}{0}$ — แก้ด้วยการแยกตัวประกอบ (Factoring), คูณสังยุค (Conjugate), ลิมิตตรีโกณมิติ, หรือกฎโลปิตาล
   - $\frac{\infty}{\infty}$ — แก้ด้วยการหารด้วยดีกรีสูงสุด หรือกฎโลปิตาล
2. **รูปผลคูณ (Product):**
   - $0 \cdot \infty$ — จัดรูปใหม่เป็น $\frac{0}{1/\infty} = \frac{0}{0}$ หรือ $\frac{\infty}{1/0} = \frac{\infty}{\infty}$
3. **รูปผลต่าง (Difference):**
   - $\infty - \infty$ — จัดรูปด้วยการคูณสังยุค หรือการหา ค.ร.น. รวมเศษส่วน
4. **รูปเลขชี้กำลัง (Exponential):**
   - $1^\infty$ — เทค $\ln$ แปลงเป็นรูป $0 \cdot \infty \to \frac{0}{0}$ หรือใช้สูตร $\lim (1 + \frac{1}{x})^x = e$
   - $0^0$ — เทค $\ln$ แปลงเป็นรูป $0 \cdot (-\infty)$
   - $\infty^0$ — เทค $\ln$ แปลงเป็นรูป $0 \cdot \infty$

### 6.2 รูปแบบที่สรุปค่าได้ทันที (Determinate Forms — ไม่ใช่ Indeterminate)
- $\frac{c}{0} \quad (c \neq 0) \implies \pm\infty$ หรือไม่มีลิมิต (DNE) ตามเครื่องหมายซ้าย-ขวา
- $\frac{0}{\infty} \implies 0$
- $\frac{\infty}{0} \implies \pm\infty$ (ตามเครื่องหมาย)
- $\infty + \infty \implies +\infty$
- $0^\infty \implies 0$

## 7. มาตรการตรวจสอบการเรนเดอร์สมการคณิตศาสตร์ (LaTeX QA Protocol)

1. **Python String Escaping:** สตริงที่มี LaTeX backslash (เช่น `\frac`, `\infty`, `\pi`) ต้องใช้ raw string (`r"..."`) หรือ double backslash (`"\\frac"`) เพื่อป้องกัน `SyntaxWarning: invalid escape sequence`
2. **เครื่องหมาย Delimiters Balanced:** สัญลักษณ์ `$` ต้องมาเป็นคู่เสมอ (จำนวน `$` ในประโยคต้องเป็นเลขคู่)
3. **การเว้นวรรคภาษาไทยติดกับสมการ:** เรียกใช้ `format_math_spacing()` ใน `utils/math_render.py` เพื่อแยกอักขระไทยออกจาก `$` ป้องกัน KaTeX parse failure
4. **KaTeX-Safe Notation:** ห้ามใช้ `\(` หรือ `\[` ให้ใช้ `$inline$` และ `$$display$$` หรือ `st.latex()` เท่านั้น
