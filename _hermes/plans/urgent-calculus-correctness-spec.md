# ข้อกำหนดแก้ไขความถูกต้องทางคณิตศาสตร์

## Problem Statement

แอปมีข้อสรุปลิมิตสองด้านผิด แสดงปริพันธ์มีเครื่องหมายเป็นพื้นที่ แสดงขอบบนปริพันธ์ผิด และวาดกราฟฟังก์ชันค่าคงที่ไม่ได้ ปัญหาเหล่านี้ยืนยันจากการทดลองผ่าน browser-box แล้ว เป้าหมายคือไม่ให้ผู้เรียนได้รับคำตอบหรือสมการที่ผิดอย่างเงียบ ๆ

## Solution

แก้ที่ helper คำนวณและพล็อตเดิม พร้อมปรับหน้าแสดงผลให้แยกคำตอบจริงจำกัด ลิมิตอนันต์ ลิมิตไม่มีอยู่ ปริพันธ์ลู่ออก และกรณีระบบยังตัดสินไม่ได้ โดยมี regression tests ก่อนแก้และทดสอบหน้าจอซ้ำหลังแก้

## User Stories

1. ผู้เรียนต้องการเห็นลิมิตซ้ายและขวาที่ถูกต้อง เพื่อไม่สรุปว่าทั้งสองเท่ากันเมื่อค่าต่างกัน
2. ผู้เรียนต้องการพื้นที่เรขาคณิตไม่ติดลบ แม้กราฟตัดกันหรือสลับลำดับฟังก์ชัน
3. ผู้เรียนต้องการสมการปริพันธ์ใช้ขอบเขตเดียวกับที่ป้อน เพื่อไม่อ่านค่าที่ถูกแต่สมการผิด
4. ผู้เรียนต้องการคำวินิจฉัยว่าปริพันธ์ลู่ออก แทนข้อความหาค่าไม่ได้ที่กำกวม
5. ผู้เรียนต้องการเห็นกราฟฟังก์ชันค่าคงที่และพื้นที่แรเงาโดยไม่มี shape mismatch
6. ผู้ทดสอบต้องการคำสั่งและหลักฐานก่อน/หลังที่ทำซ้ำได้ โดยไม่แก้เฉลยอ้างอิงให้ตามผลผิด

## Implementation Decisions

- ใช้ solver, plotter และหน้า UI เดิม ไม่เพิ่ม dependencies ไม่รื้อ parser ไม่สร้าง framework
- คง signature และคีย์เดิมของ dict แต่แก้ความหมายของค่าที่เป็นข้อผิดพลาด ไม่เก็บผลผิดเพื่อให้ test เดิมผ่าน
- เพิ่ม `status` เฉพาะ helper ลิมิตและปริพันธ์ไม่ตรงแบบ: `finite`, `infinite`, `dne`, `divergent`, `unsupported`, `error` ตามประเภทงาน
- `ok=True` หมายถึงคำนวณหรือวินิจฉัยได้ ไม่ได้หมายความว่ามีค่าจำกัดเสมอ; `unsupported` และ `error` ใช้ `ok=False` พร้อมข้อความไทย
- ลิมิต `dne` ต้องมี `result=None` ทั้งเครื่องคิดเลขและบทเรียน; ห้ามแสดงสมการเท่ากับอนันต์จากลิมิตทางขวาเพียงข้างเดียว
- เครื่องคิดเลขยังคืน SymPy object สำหรับคำตอบลิมิตที่มีอยู่; helper บทเรียนคืน float เฉพาะค่าจำกัดและใช้ `None` สำหรับลิมิตอนันต์
- พื้นที่หมายถึงปริพันธ์ของค่าสัมบูรณ์ของผลต่างบนช่วงจริงจำกัดและต่อเนื่อง หาก exact integration หรือการแยกช่วงยังตัดสินไม่ได้ ต้องแจ้งข้อจำกัด ไม่ใช้ numeric sign scan เป็นใบรับรองว่าพบจุดตัดครบ
- ปริพันธ์ไม่ตรงแบบต้องแยกการลู่ออกจาก domain error และผล CAS ที่ยังไม่ประเมิน ห้ามใช้ principal value แทนปริพันธ์จริง
- รุ่นแก้เร่งด่วนรองรับช่วงที่ไม่มี singularity ภายใน หากยังแยกเอกฐานภายในไม่ได้อย่างถูกต้อง ให้ `unsupported` โดยไม่รายงานค่าจำกัด; singular endpoints ที่ตรวจได้ยังรองรับ
- การพล็อตต้องกระจาย scalar ให้มี shape เดียวกับ sample grid และไม่แทนค่าที่ไม่จำกัดด้วยศูนย์

## Testing Decisions

- ตรวจพฤติกรรมผ่าน public helpers เดิม ไม่ผูกเกณฑ์กับชื่อ private function หรือจำนวนขั้นตอนที่ไม่มีความหมายต่อคำตอบ
- ใช้คำตอบอ้างอิง exact/analytic ไม่ใช้ผลจาก production helper สร้าง expected value
- เปลี่ยน test เดิมที่ยอมรับอนันต์สำหรับลิมิตสองด้านของ 1/x ที่ 0 ให้เป็นเกณฑ์ที่ถูกต้อง พร้อมอธิบายเหตุผลใน diff
- ผ่าน unit tests ไม่พอ ต้องตรวจ input ที่ commit แล้ว สมการ คำวินิจฉัย และภาพที่โหลดผ่าน browser-box
- ชุดข้อมูลเดิมมีข้อเสนอ validation สองรายการที่ยังไม่อยู่ในขอบเขตรุ่นเร่งด่วน ต้องแยกผลเหล่านี้จากข้อผิดพลาดที่แก้แล้ว

## Out of Scope

เปลี่ยนธีม ปรับ survey เพิ่ม worksheet ตรวจคณิตศาสตร์ทั้งคลังบทเรียน แก้ navigation ของหน้าปริมาตร เพิ่ม washer method แก้ parser security ทำ load test เพิ่ม hard timeout ทั่วแอป และ commit/push
