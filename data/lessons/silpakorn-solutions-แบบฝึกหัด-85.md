# แบบฝึกหัด 8.5

1\. จงแสดงว่าสมการเชิงอนุพันธ์ต่อไปนี้เป็นสมการแบบแม่นตรง พร้อมทั้งหาผลเฉลยของสมการ

1.1 $\frac{dy}{dx} = -\frac{2xy^2 + 2}{2x^2y}$

1.2 $(x+y)dx-(y-x)dy=0$

1.3 $(\cos x \cos y+x)dx-(\sin x \sin y+y)dy=0$

1.4 $(e^x y+1)dx+(e^x-1)dy=0$

1.5 $\frac{dy}{dx} = -\frac{2x+y}{x^2-1}$

1.6 $(x-y \cos x)dx-\sin x dy=0$

2\. จงหาตัวประกอบการอินทิเกรตของสมการเชิงอนุพันธ์ต่อไปนี้ พร้อมทั้งหาผลเฉลยของสมการ

2.1 $(y^2+2xy)dx-x^2dy=0$

2.2 $y dx+(y-x)dy=0$

2.3 $(x^2+2y)dx-x dy=0$

2.4 $(x^4-x+ y)dx-x dy=0$

2.5 $(x^2+y^2)dx+3xy dy=0$
