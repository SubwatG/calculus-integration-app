# แบบฝึกหัด 3.5

1\. ในแต่ละข้อต่อไปนี้จงหาเส้นกำกับแนวนอน (ถ้ามี) ของกราฟของฟังก์ชันที่กำหนดให้

1.1 $f(x) = \frac{3}{x+5}$

1.2 $f(x) = \frac{3x^2}{1+x^2}$

1.3 $f(x) = \frac{x^3}{1-x^3}$

1.4 $f(x) = \sqrt{\frac{1+7x^2}{x^2+3}}$

2\. ในแต่ละข้อต่อไปนี้จงหาเส้นกำกับแนวตั้ง (ถ้ามี) ของกราฟของฟังก์ชันที่กำหนดให้

2.1 $f(x) = \frac{1}{x-4}$

2.2 $f(x) = \frac{x^2+4}{x^2-4}$

2.3 $f(x) = \frac{4}{4+5x+x^2}$

2.4 $f(x) = \frac{x^2+5x+6}{x^2-5x+6}$

3\. ในแต่ละข้อต่อไปนี้จงร่างกราฟของฟังก์ชัน $f$ ที่สอดคล้องกับเงื่อนไขที่กำหนดให้

3.1 $f''(2)=0$, $f(2)=-1$, $f(0)=0$, $f'(x)0$ เมื่อ $x>2$, $f''(x)4$, $f''(x)>0$ เมื่อ $1<x<4$, $\lim_{x\to\infty} f(x)=1$ และ $f(-x)=f(x)$

3.2 $f(1)=f'(1)=0$, $\lim_{x\to 2^+} f(x)=\infty$, $\lim_{x\to 2^-} f(x)=-\infty$, $\lim_{x\to 0} f(x)=-\infty$, $\lim_{x\to -\infty} f(x)=\infty$, $\lim_{x\to \infty} f(x)=0$, $f''(x)>0$ เมื่อ $x>2$, $f''(x)<0$ เมื่อ $x<0$ และเมื่อ $0<x<2$

4\. ในแต่ละข้อต่อไปนี้จงวาดกราฟของฟังก์ชัน $f$ ที่กำหนดให้

4.1 $f(x) = 2x^3 - 3x^2$

4.2 $f(x) = \frac{x+4}{x-4}$

4.3 $f(x) = |4-x^2|$

4.4 $f(x) = \frac{1}{x(x-4)}$

4.5 $f(x) = \frac{x}{(2x+1)^2}$

4.6 $f(x) = 16-20x^3 + 3x^5$

4.7 $f(x) = x^4 - 6x^2$
