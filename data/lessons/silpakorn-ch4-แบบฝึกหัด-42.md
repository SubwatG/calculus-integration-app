# แบบฝึกหัด 4.2.1

1\. จงพิจารณาว่าอินทิกรัลในแต่ละข้อใดต่อไปนี้ เป็นอินทิกรัลไม่ตรงแบบหรือไม่ พร้อมทดสอบ การสู่เข้าของอินทิกรัลไม่ตรงแบบนั้น

1.1 $\int_0^1 \frac{dx}{(x^2+9)^{\frac{3}{2}}}$

1.2 $\int_0^{\pi/2} \tan x dx$

1.3 $\int_1^3 \frac{dx}{x}$

1.4 $\int_0^1 \left(\frac{1}{x^2} + 1\right) dx$

1.5 $\int_0^{\pi/2} \frac{\sin x}{1-\cos x} dx$

1.6 $\int_{2-\sqrt{x+1}}^{3} \frac{dx}{x-3}$

2\. จงหาอินทิกรัลในแต่ละข้อต่อไปนี้ ถ้าอินทิกรัลลู่เข้า

2.1 $\int_0^1 \frac{dx}{\sqrt{1-x}}$

2.2 $\int_0^1 x^{1/2} dx$

2.3 $\int_0^2 |x-2| dx$

2.4 $\int_0^2 x \ln x dx$

2.5 $\int_0^2 \frac{dx}{x^2 - 1}$

2.6 $\int_0^{\pi/2} \cot x dx$

2.7 $\int_0^2 \frac{dx}{(2-x)^{\frac{1}{3}}}$

2.8 $\int_0^{\pi/2} \sec^2 x dx$

2.9 $\int_0^2 \frac{dx}{\sqrt{2x-x^2}}$

3\. จงหาจำนวนจริงที่ไม่เป็นลบ $n$ ที่ทำให้อินทิกรัล $\int_0^x e^{-t} dt$ มีค่าเป็นจำนวนจริง
