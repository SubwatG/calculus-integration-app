## 6.2 6.2 ลิมิตของฟังก์ชันสองตัวแปร

ในการศึกษาที่ผ่านมาเราใช้สัญลักษณ์ $\lim_{x \to a} f(x) = L$ แทนข้อความที่ว่า ถ้า $x$ เข้าใกล้ $a$ (ไม่ว่าจากทางซ้ายหรือทางขวาของ $a$) โดยที่ $x \neq a$ แล้ว $f(x)$ จะเข้าใกล้จำนวนจริง $L$ เพียง จำนวนเดียว เราจะขยายแนวคิดเรื่องลิมิตของฟังก์ชันตัวแปรเดียวไปยังลิมิตของฟังก์ชันสองตัวแปร นั่นคือ เราจะใช้สัญลักษณ์ $\lim_{(x,y) \to (a,b)} f(x,y) = L$ แทนข้อความที่ว่า ถ้า $(x,y)$ เข้าใกล้ $(a,b)$ (ไม่ว่า จะเข้าใกล้ $(a,b)$ ในทิศทางใด) โดยที่ $(x,y) \neq (a,b)$ แล้ว $f(x,y)$ จะเข้าใกล้จำนวนจริง $L$ เพียง


จำนวนเดียว แต่ในกรณีนี้ $(x, y)$ และ $(a, b)$ อยู่บนระนาบ $xy$ ทั้งคู่ จึงทำให้ทิศทางที่ $(x, y)$ เข้าใกล้ $(a, b)$ มีได้มากมายนับไม่ถ้วน (รูป 6.2.1)

> [Figure] ภาพแสดงระบบพิกัดคาร์ทีเซียน โดยมีแกน x และแกน y ตัดกันที่จุดกำเนิด (0,0) มีเส้นโค้งหลายเส้นผ่านจุดกำเนิดและจุดอื่นๆ เช่น $(a, b)$ ซึ่งเป็นจุดที่กำหนดโดยจุดกำเนิดและจุดอื่นๆ นอกจากนี้ยังมีเส้นตรงแนวนอน $y = b$ และเส้นตรงแนวตั้ง $x = a$ ซึ่งตัดกันที่จุด $(a, b)$ แสดงถึงการเข้าใกล้หรือความสัมพันธ์ระหว่างสองตัวแปร

รูป 6.2.1

ตัวอย่างเช่น หากเรากล่าวว่า $(x, y)$ เข้าใกล้ $(1, 0)$ จะเห็นว่า $(x, y)$ อาจเข้าใกล้ $(1, 0)$ ตามแนวแกน $x$ ซึ่งจะหมายความว่า $(x, y)$ เคลื่อนที่บนแกน $x$ เข้าใกล้ $(1, 0)$ ดังรูป 6.2.2 (ก) หรือ $(x, y)$ อาจเข้าใกล้ $(1, 0)$ ตามแนวเส้นตรง $y=1-x$ ซึ่งหมายความว่า $(x, y)$ เคลื่อนที่บนเส้นตรง $y=1-x$ เข้าใกล้ $(1, 0)$ ดังรูป 6.2.2 (ข) หรือ $(x, y)$ อาจเข้าใกล้ $(1, 0)$ ตามแนวเส้นโค้งพาราโบลา $y=(x-1)^2$ ซึ่งหมายความว่า $(x, y)$ เคลื่อนที่บนเส้นโค้งพาราโบลา $y=(x-1)^2$ เข้าใกล้ $(1, 0)$ ดังรูป 6.2.2 (ค)

> [Figure] ภาพแสดงระบบพิกัดคาร์ทีเซียน โดยมีแกน x และแกน y ตัดกันที่จุดกำเนิด (0,0) มีจุดสามจุดที่ระบุไว้พร้อมคำอธิบาย: (ก) จุด $(1, 0)$ อยู่บนเส้นตรงแนวนอน $y = 0$ ซึ่งแสดงถึงการเข้าใกล้ตามแกน x, (ข) จุด $(1, 0)$ อยู่บนเส้นตรง $y = 1 - x$ ซึ่งแสดงถึงการเข้าใกล้ตามเส้นตรง, และ (ค) จุด $(1, 0)$ อยู่บนเส้นโค้งพาราโบลา $y = (x-1)^2$ ซึ่งแสดงถึงการเข้าใกล้ตามเส้นโค้งพาราโบลา

รูป 6.2.2

เราจะให้บทนิยามที่ชัดเจนของลิมิตของฟังก์ชันสองตัวแปร โดยเริ่มจากบทนิยามต่อไปนี้


บทนิยาม 6.2.1 จะเรียกเซตของจุดที่อยู่ภายในวงกลมซึ่งไม่รวมจุดที่อยู่บนเส้นขอบวงกลมว่าจาน เปิด (open disk) และเรียกเซตที่ประกอบไปด้วยจุดที่อยู่ภายในวงกลมและจุดที่อยู่บนเส้นขอบวงกลม ว่าจานปิด (closed disk)

บทนิยาม 6.2.2 ให้ $D$ เป็นจานเปิดใน $\mathbb{R}^2$ และ $(a,b) \in D$ ให้ $L \in \mathbb{R}$ และ $f$ เป็นฟังก์ชันสองตัว แปรที่นิยามบน $D - \{(a,b)\}$ เรากล่าวว่า $L$ เป็น ลิมิตของ $f(x,y)$ เมื่อ $(x,y)$ เข้าใกล้ $(a,b)$ และเขียนแทนด้วยสัญลักษณ์ $\lim_{(x,y) \to (a,b)} f(x,y) = L$ ถ้าสำหรับแต่ละจำนวนจริงบวก $\varepsilon$ จะมีจำนวน จริงบวก $\delta$ ที่ทำให้

$$|f(x,y)-L|<\varepsilon$$

สำหรับทุก ๆ $(x,y) \in D$ ซึ่ง $0 < \sqrt{(x-a)^2+(y-b)^2}<\delta$

เราอาจอธิบายความหมายของข้อความ $\lim_{(x,y) \to (a,b)} f(x,y)=L$ ในเชิงเรขาคณิตได้ดังนี้ สำหรับจำนวนจริงบวก $\varepsilon$ พิจารณาช่วงเปิด $(L-\varepsilon,L+\varepsilon)$ บนแกน z ถ้า $\lim_{(x,y) \to (a,b)} f(x,y)=L$ แล้ว จะมีจำนวนจริงบวก $\delta$ ซึ่งสำหรับทุก ๆ $(x,y)$ ที่อยู่ภายในวงกลมที่มีจุดศูนย์กลางที่ $(a,b)$ และ รัศมีเท่ากับ $\delta$ โดยที่ $(x,y) \neq (a,b)$ จะได้ว่า $f(x,y)$ จะต้องอยู่ในช่วง $(L-\varepsilon,L+\varepsilon)$ (ดูรูป 6.2.3)

> [Figure] ภาพแสดงระนาบพิกัดฉาก มีแกน x และแกน y โดยมีจุดกำเนิดอยู่ที่ $(a,b)$ ซึ่งเป็นจุดศูนย์กลางของวงกลมที่มีรัศมี $\delta$ รอบๆ วงกลมนั้นมีพื้นที่โค้งคล้ายจานเปิดที่กำหนดโดยสมการ $|f(x,y)-L|<\varepsilon$ ซึ่งแสดงด้วยเส้นโค้งที่ล้อมรอบจุด $(a,b)$ พร้อมระบุพิกัด R บนแกน y และ L บนแกน x เพื่อแสดงตำแหน่งของจุดต่างๆ บนระนาบ

ทฤษฎีบท 6.2.4 ให้ $f$ และ $g$ เป็นฟังก์ชันสองตัวแปร โดยที่ $\lim_{(x,y)\rightarrow(a,b)} f(x,y)=L_1$ และ $\lim_{(x,y)\rightarrow(a,b)} g(x,y)=L_2$ เมื่อ $L_1$ และ $L_2$ เป็นจำนวนจริง จะได้ว่า
1. $\lim_{(x,y)\rightarrow(a,b)} c = c$ เมื่อ $c$ เป็นค่าคงตัวใด ๆ
2. $\lim_{(x,y)\rightarrow(a,b)} cf(x,y)=c\lim_{(x,y)\rightarrow(a,b)} f(x,y)$ เมื่อ $c$ เป็นค่าคงตัวใด ๆ
3. $\lim_{(x,y)\rightarrow(a,b)} (f(x,y)+g(x,y))=\lim_{(x,y)\rightarrow(a,b)} f(x,y)+\lim_{(x,y)\rightarrow(a,b)} g(x,y)=L_1+L_2$
4. $\lim_{(x,y)\rightarrow(a,b)} (f(x,y)g(x,y))=\lim_{(x,y)\rightarrow(a,b)} f(x,y)\lim_{(x,y)\rightarrow(a,b)} g(x,y)=L_1 L_2$
5. $\lim_{(x,y)\rightarrow(a,b)} \frac{f(x,y)}{g(x,y)}=\frac{\lim_{(x,y)\rightarrow(a,b)} f(x,y)}{\lim_{(x,y)\rightarrow(a,b)} g(x,y)}=\frac{L_1}{L_2}$ เมื่อ $L_2 \neq 0$

บทนิยาม 6.2.8 จะเรียกฟังก์ชันสองตัวแปร $f$ ว่าพหุนาม (polynomial) ในตัวแปร $x$ และ $y$ เมื่อ $f$ เขียนได้ในรูปของผลบวกของพจนที่อยู่ในรูป $cx^n y^m$ โดยที่ $c$ เป็นค่าคงตัวและ $n$ และ $m$ เป็นจำนวนเต็มที่ไม่เป็นลบ และจะเรียกฟังก์ชันสองตัวแปรที่เขียนในรูป $\frac{P(x,y)}{Q(x,y)}$ ว่าฟังก์ชันตรรกยะ (rational function) ในตัวแปร $x$ และ $y$ เมื่อ $P(x,y)$ และ $Q(x,y)$ ต่างเป็นพหุนามในตัวแปร $x$ และ $y$

ตัวอย่าง 6.2.9 $x^3-4xy^2+y-x$ และ $x^2y+y^2+4xy$ ต่างเป็นพหุนามในตัวแปร $x$ และ $y$ ในขณะที่ $\frac{x^2y+xy^2+3}{xy-1}$ และ $\frac{x^3y^4+2xy^2}{x^2y+5}$ ต่างเป็นฟังก์ชันตรรกยะ

ทฤษฎีบท 6.2.10 ถ้า $P(x,y)$ เป็นพหุนามในตัวแปร $x$ และ $y$ แล้ว $\lim_{(x,y)\to(a,b)} P(x,y)=P(a,b)$

ทฤษฎีบท 6.2.11 ถ้า $P(x,y)$ และ $Q(x,y)$ ต่างเป็นพหุนามในตัวแปร $x$ และ $y$ แล้ว
$$\lim_{(x,y)\to(a,b)} \frac{P(x,y)}{Q(x,y)} = \frac{P(a,b)}{Q(a,b)}$$
เมื่อ $Q(a,b) \neq 0$

**ตัวอย่าง 6.2.14** จงแสดงว่า $\lim _ { (x,y) \rightarrow (0,0) } \frac { xy } { x ^ { 2 } + y ^ { 2 } }$ หาไม่ได้

**วิธีทำ** จะเห็นว่าถ้าให้ $(x,y)$ เข้าใกล้ $(0,0)$ ตามแนวแกน $x$ จะได้ว่า $y=0$ และ $x$ มีค่าเข้าใกล้ $0$ แต่ไม่เท่ากับ $0$ ซึ่งทำให้

$$ \lim _ { (x,y) \rightarrow (0,0) } \frac { xy } { x ^ { 2 } + y ^ { 2 } } = \lim _ { (x,y) \rightarrow (0,0) } \frac { x \cdot 0 } { x ^ { 2 } + 0 } = 0 $$

ในขณะเดียวกันถ้าให้ $(x,y)$ เข้าใกล้ $(0,0)$ ตามแนวเส้นตรง $y=x$ จะทำให้

$$ \lim _ { (x,y) \rightarrow (0,0) } \frac { xy } { x ^ { 2 } + y ^ { 2 } } = \lim _ { (x,y) \rightarrow (0,0) } \frac { x \cdot x } { x ^ { 2 } + x ^ { 2 } } = \lim _ { (x,y) \rightarrow (0,0) } \frac { x ^ { 2 } } { 2 x ^ { 2 } } = \frac { 1 } { 2 } $$

แสดงว่า $\lim _ { (x,y) \rightarrow (0,0) } \frac { xy } { x ^ { 2 } + y ^ { 2 } }$ หาไม่ได้

**ตัวอย่าง 6.2.15** จงแสดงว่า $\lim _ { (x,y) \rightarrow (1,0) } \frac { y } { x + y - 1 }$ หาไม่ได้

**วิธีทำ** จะเห็นว่าถ้าให้ $(x,y)$ เข้าใกล้ $(1,0)$ ตามแนวเส้นตรง $x=1$ จะได้ว่า $x=1$ และ $y$ มีค่าเข้าใกล้ $0$ แต่ไม่เท่ากับ $0$ ซึ่งทำให้

$$ \lim _ { (x,y) \rightarrow (1,0) } \frac { y } { x + y - 1 } = \lim _ { (x,y) \rightarrow (1,0) } \frac { y } { 1 + y - 1 } = \lim _ { (x,y) \rightarrow (1,0) } \frac { y } { y } = \lim _ { (x,y) \rightarrow (1,0) } 1 = 1 $$


ในขณะเดียวกันถ้าให้ $(x, y)$ เข้าใกล้ $(1, 0)$ ตามแนว $y = (x-1)^2$ จะทำให้

$$\lim_{(x,y)\rightarrow(1,0)} \frac{y}{x+y-1} = \lim_{(x,y)\rightarrow(1,0)} \frac{(x-1)^2}{(x-1)+(x-1)^2} = \lim_{(x,y)\rightarrow(1,0)} \frac{(x-1)(x-1)}{(x-1)(1+(x-1))} = \lim_{(x,y)\rightarrow(1,0)} \frac{(x-1)}{x} = 0$$

6.3 ความต่อเนื่องของฟังก์ชันหลายตัวแปร

ในหัวข้อนี้เราจะศึกษาความต่อเนื่องของฟังก์ชันสองตัวแปรโดยขยายแนวคิดเรื่องความต่อเนื่องของฟังก์ชันตัวแปรเดียว เราได้ทราบมาแล้วว่า ถ้า $f$ เป็นฟังก์ชันตัวแปรเดียวที่ต่อเนื่องที่ $a$ แล้ว $\lim_{x\to a} f(x) = f(a)$ เราสามารถนิยามความต่อเนื่องของฟังก์ชันหลายตัวแปรได้ในทำนองเดียวกัน ดังนี้

**บทนิยาม 6.3.1** ให้ $f$ เป็นฟังก์ชันหลายตัวแปร เรากล่าวว่า $f$ ต่อเนื่อง (continuous) ที่ $(a_1,a_2,...,a_n)$ ถ้า $f$ สอดคล้องเงื่อนไขทั้ง 3 ข้อต่อไปนี้
1. $f(a_1,a_2,...,a_n)$ หาได้
2. $\lim_{(x_1,x_2,...,x_n)\to(a_1,a_2,...,a_n)} f(x_1,x_2,...,x_n)$ หาได้
3. $\lim_{(x_1,x_2,...,x_n)\to(a_1,a_2,...,a_n)} f(x_1,x_2,...,x_n) = f(a_1,a_2,...,a_n)$

ในกรณีที่ $f$ ไม่สอดคล้องกับข้อใดข้อหนึ่งใน 3 ข้อข้างต้น เรากล่าวว่า $f$ **ไม่ต่อเนื่อง** (discontinuous) ที่ $(a_1,a_2,...,a_n)$
