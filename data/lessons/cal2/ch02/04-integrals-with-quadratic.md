# 2.5 อินทิกรัลที่ประกอบด้วยนิพจน์กำลังสอง

หัวข้อนี้เราจะแสดงการหาอินทิกรัลของฟังก์ชันที่ประกอบด้วยนิพจน์กำลังสอง
$a x^2 + bx + c$ โดยเริ่มพิจารณาจากการหาอินทิกรัลในรูป $\int \frac{dx}{ax^2 + bx + c}$
ตัวอย่าง 2.5.1 ให้ $a > 0$ และ $c > 0$ จงหา

1. $\int \frac{dx}{ax^2 + c}$
2. $\int \frac{dx}{4x^2 + 1}$

วิธีทำ 1. เราพิจารณาว่าอินทิกรัล $\int \frac{dx}{ax^2 + c}$ อยู่ในรูปที่คล้ายกับสูตรพื้นฐานการอินทิเกรตสูตร
ที่ 13 เราจึงจัดรูปอินทิกรัลเสียใหม่ ดังนี้
$\int \frac{dx}{ax^2 + c} = \frac{1}{c} \int \frac{dx}{x^2 + 1}$
แล้วทำการอินทิเกรตด้วยเทคนิคโดยการแทน $u = \sqrt{\frac{a}{c}} x$ ซึ่งทำให้ได้ $du = \sqrt{\frac{a}{c}} dx$ และได้


$$ \int \frac{dx}{ax^2+c} = \frac{1}{c} \sqrt{\frac{c}{a}} \frac{du}{u^2+1} = \frac{1}{\sqrt{ac}} \tan^{-1} u + C = \frac{1}{\sqrt{ac}} \sqrt{\frac{a}{c}} x + C $$

2. ให้ $u=2x$ แล้วได้ $du=2dx$ ซึ่งทำให้ได้
$$ \int \frac{dx}{4x^2+1} = \frac{1}{2} \int \frac{du}{u^2+1} = \frac{1}{2} \tan^{-1} u + C = \frac{1}{2} \tan^{-1}(2x)+C $$
รูปอินทิกรัลข้างต้นถือเป็นรูปแบบพื้นฐานในการหาอินทิกรัลของการหาอินทิกรัลนิพจน์กำลังสอง บางรูปเช่น
$$ \int \frac{dx}{ax^2+bx+c}, \int \frac{x dx}{ax^2+bx+c} $$
โดยทั่วไปในการหาอินทิกรัลของฟังก์ชันที่ประกอบไปด้วยนิพจน์กำลังสอง $ax^2 + bx + c$ ซึ่ง $b \neq 0$ มักอาศัยเทคนิคการทำให้นิพจน์ $ax^2 + bx + c$ เป็นกำลังสองสมบูรณ์ ดังนี้
$$
\begin{align*}
ax^2+bx+c  &= a \left( x^2 + \frac{b}{a} x + \frac{c}{a} \right) = a \left( x^2 + \frac{b}{a} x + \frac{b^2}{4a^2} + \frac{c}{a} - \frac{b^2}{4a^2} \right) \\[0.5em]
&= a \left( x + \frac{b}{2a} \right)^2 + \frac{4ac-b^2}{4a^2} + \frac{4ac-b^2}{4a^2}
\end{align*}
$$
โดยในการอินทิเกรตนี้ เราจะให้ $u = x + \frac{b}{2a}$ เป็นตัวแปรใหม่ในการอินทิเกรต ดังจะแสดงใน ตัวอย่างต่อไปนี้

**ตัวอย่าง 2.5.2 จงหา**
1. $\int \frac{dx}{x^2+4x+5}$
2. $\int \frac{dx}{\sqrt{2x-x^2}}$
3. $\int \frac{dx}{4x^2+8x+13}$

**วิธีทำ** 1. เขียน $x^2 + 4x + 5$ ในรูปกำลังสองสมบูรณ์ได้ดังนี้
$$ x^2 + 4x + 5 = (x^2 + 4x + 4) - 4 + 5 = (x+2)^2 + 1 $$
แล้วกำหนดตัวแปรใหม่ $u = x + 2$ จะได้ $du = dx$ ทำให้ได้
$$ \int \frac{dx}{x^2+4x+5} = \int \frac{du}{(x+2)^2 + 1} = \int \frac{du}{u^2 + 1} = \tan^{-1} u + C = \tan^{-1}(x+2)+C $$
2. เพราะว่า $2x-x^2 = -(x^2-2x+1)-1 = -(x^2-2x+1)+1 = -(x-1)^2 + 1$ ดังนั้น เมื่อให้ $u=x-1$ จะได้ $du = dx$ และทำให้ได้


$$ \int \frac{dx}{\sqrt{2x-x^2}} = \int \frac{du}{\sqrt{1-u^2}} = \sin^{-1}u + C = \sin^{-1}(x-1)+C $$

3. เพราะว่า $4x^2+8x+13=4(x^2+2x+1)-1+13=4(x-1)^2-4+13$
$= 4(x+1)^2+9=4\left[(x+1)^2+\left(\frac{3}{2}\right)^2\right]$

เมื่อเราให้ $x+1=\frac{3}{2}\tan\theta$ จะได้ $dx=\frac{3}{2}\sec^2\theta d\theta$ และ $4\left[(x+1)^2+\frac{9}{4}\right]=\frac{9}{4}\sec^2\theta$
เพราะฉะนั้น
$$
\begin{align*}
\int \frac{dx}{4x^2+8x+13}  &= \frac{1}{4} \int \frac{dx}{(x+1)^2+\frac{9}{4}} = \frac{1}{4} \int \frac{\frac{3}{2}\sec^2\theta d\theta}{\frac{9}{4}\sec^2\theta} = \frac{1}{6} \int d\theta = \frac{\theta}{6} + C \\[0.5em]
&= \frac{1}{6} \tan^{-1}\frac{2(x+1)}{3} + C
\end{align*}
$$

## 2.6 การอินทิเกรตฟังก์ชันตรรกยะ

ในหัวข้อนี้เราจะแสดงวิธีการหา $\int f(x) dx$ เมื่ออินทิแกรนด์ $f(x)$ เป็นฟังก์ชันตรรกยะ (rational function) กล่าวคือ $f(x)=\frac{p(x)}{q(x)}$ เมื่อ $p(x)$ และ $q(x)$ เป็นฟังก์ชันพหุนามและ $q(x)\neq 0$

ถ้ากำลังของ $p(x)$ น้อยกว่ากำลังของ $q(x)$ เราจะเรียก $\frac{p(x)}{q(x)}$ ว่า ฟังก์ชันตรรกยะ แท้ (proper rational function) แต่ถ้ากำลังของ $p(x)$ มากกว่าหรือเท่ากับกำลังของ $q(x)$ เราสามารถหาพหุนาม $g(x)$ และ $r(x)$ ที่ทำให้

$$ \frac{p(x)}{q(x)}=g(x)+\frac{r(x)}{q(x)} $$

โดยที่ $\frac{r(x)}{q(x)}$ เป็นฟังก์ชันตรรกยะแท้ ดังนั้น


$$ \int \frac{p(x)}{q(x)}dx = \int g(x) dx + \int \frac{r(x)}{q(x)} dx $$
และเนื่องจากการอินทิเกรตฟังก์ชันพหุนาม $\int g(x) dx$ ทำได้โดยง่าย เราจึงกล่าวถึงการอินทิเกรต $\int \frac{p(x)}{q(x)} dx$ เฉพาะเมื่อ $\frac{p(x)}{q(x)}$ เป็นฟังก์ชันตรรกยะแท้ ด้วยเทคนิคที่เรียกว่า การเขียนฟังก์ชันตรรกยะในรูปเศษส่วนย่อย (partial fraction expansion) โดยดำเนินการตามลำดับขั้นตอนต่อไปนี้

**ขั้นที่ 1 : แยกตัวประกอบ $q(x)$**
เราทราบมาแล้วว่าฟังก์ชันพหุนามใด ๆ ที่มีกำลังมากกว่าหรือเท่ากับ 2 จะเขียนได้ในรูปผลคูณของฟังก์ชันพหุนามเชิงเส้นและ/หรือพหุนามกำลังสองซึ่งลดทอนไม่ได้ สังเกตว่าพหุนามกำลังสอง $ax^2+bx+c$ ลดทอนไม่ได้ ก็ต่อเมื่อ $b^2 < 4ac$ (โดยใช้หลักตรรกศาสตร์ เราอาจกล่าวได้ว่า $ax^2+bx+c$ ลดทอนได้ ก็ต่อเมื่อ $b^2 \geq 4ac$) ตัวอย่างเช่นพหุนาม $x^2+1$ ลดทอนไม่ได้ เพราะ $0=b^2<4ac=4(1)(-1)=-4$

**ตัวอย่าง 2.6.1** จงแยกตัวประกอบของพหุนามต่อไปนี้ (ถ้าแยกได้)
1. $x^3+2x^2+2x+1$
2. $x^3-2x^2-5x+6$
3. $x^4+1$

**วิธีทำ**
1. เพราะว่า $(-1)^3+2(-1)^2+2(-1)+1=0$ ดังนั้น $x+1$ เป็นตัวประกอบหนึ่งของ $x^3+2x^2+2x+1$ ทำให้ได้
$x^3+2x^2+2x+1 = (x+1)(x^2+x+1)$
โดยที่ $x^2+x+1$ ลดทอนไม่ได้ เพราะ $1=b^2 < 4ac=4(1)(1)=4$

2. เพราะว่า $(1)^3-2(1)^2-5(1)+6=0$ ดังนั้น $x-1$ เป็นตัวประกอบหนึ่ง ทำให้ได้
$x^2-2x^2-5x+6 = (x-1)(x^2-x-6) = (x-1)(x+2)(x-3)$

3. เพราะว่ากำลังของ $x^4+1$ มากกว่า 2 ดังนั้นพหุนามนี้แยกตัวประกอบได้ เราจึงสมมติว่า
$x^4+1 = (x^2+ax+1)(x^2+bxb+1)$
แล้วจะได้ $a=\pm\sqrt{2}$ และ $b=\pm\sqrt{2}$ เพราะฉะนั้น
$x^4+1 = (x^2+\sqrt{2}x+1)(x^2-\sqrt{2}x+1)$

**ตัวอย่าง 2.6.3** จงหาค่าคงตัว $k_1, k_2$ และ $k_3$ ของ $\frac{x^2+2x+3}{x(x-1)(x+1)} = \frac{k_1}{x} + \frac{k_2}{x-1} + \frac{k_3}{x+1}$

**วิธีทำ** รวมพจน์ทางขวามือก่อน และเนื่องจากตัวเศษของทั้งสองข้างจะต้องเท่ากัน เราจึงได้เอกลักษณ์
$x^2 + 2x + 3 = k_1(x - 1)(x + 1) + k_2x(x + 1) + k_3x(x - 1)$
ซึ่งเป็นจริงสำหรับทุก ๆ จำนวนจริง $x$ ดังนั้นถ้าเราแทนค่า $x = -1$, 0 และ 1 จะได้สมการตามลำดับต่อไปนี้เป็นจริงเช่นกัน
ถ้า $x = -1$ จะได้ $(-1)^2 + 2(-1) + 3 = 0 + 0 + k_3(-1)(-1-1) = 2k_3$ ดังนั้น $k_3 = 1$
ถ้า $x = 0$ จะได้ $3 = k_1(-1)(1)$ ดังนั้น $k_1 = -3$
ถ้า $x = 1$ จะได้ $1 + 2(1) + 3 = k_2(1)(1 + 1)$ ดังนั้น $k_2 = 3$

ทำให้ได้
$\frac{x^2+2x+3}{x(x-1)(x+1)} = \frac{-3}{x} + \frac{3}{x-1} + \frac{1}{x+1}$

**ตัวอย่าง 2.6.4** จงหาค่าคงตัวของสมการ $\frac{x^2+7x+1}{(x+1)^2(2x+1)} = \frac{k_1}{x+1} + \frac{k_2}{(x+1)^2} + \frac{A}{(2x+1)}$

**วิธีทำ** หลังจากรวมพจน์ทางขวาแล้ว ตัวเศษของทั้งสองข้างสมการจะเท่ากัน ทำให้ได้
$x^2 + 7x + 1 = k_1(x + 1)(2x + 1) + k_2(2x + 1) + A(x + 1)^2$
$= k_1(2x^2 + 3x + 1) + k_2(2x + 1) + A(x^2 + 2x + 1)$
$= (2k_1 + A)x^2 + (3k_1 + 2k_2 + 2A)x + (k_1 + k_2 + A)$

และโดยการเทียบสัมประสิทธิ์จะได้ระบบสมการ
$2k_1 + A = 1$
$3k_1 + 2k_2 + 2A = 7$
$k_1 + k_2 + A = 1$
