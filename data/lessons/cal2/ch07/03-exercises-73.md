7.4 กราฟในระบบพิกัดเชิงขั้ว

กราฟของความสัมพันธ์ในระบบพิกัดเชิงขั้วที่เขียนอยู่ในรูป
$$r = f(\theta) \quad \text{หรือ} \quad F(r,\theta)=0 \quad (7.4.1)$$
ประกอบด้วยจุด $P$ ที่มีอย่างน้อยหนึ่งพิกัดเชิงขั้วที่แทน $(r,\theta)$ โดยที่คู่อันดับนั้นๆ สอดคล้องกับสมการในระบบพิกัดเชิงขั้ว

การวาดกราฟในระบบพิกัดเชิงขั้วสามารถทำได้เช่นเดียวกับการวาดกราฟในระบบพิกัดฉาก นั่นคืออาจใช้วิธีการลงจุด หรือการแปลงสมการในระบบพิกัดเชิงขั้วให้เป็นสมการในระบบพิกัดฉากก่อนโดยใช้ความสัมพันธ์
$$r=\sqrt{x^2+y^2}, \quad \theta=\arctan\frac{y}{x} \quad \text{เมื่อ } x \neq 0 \quad (7.4.2)$$
แล้วพิจารณาการวาดกราฟในระนาบด้วยระบบพิกัดฉากต่อไป

**ตัวอย่าง 7.4.1** จงวาดกราฟของสมการ $r=1$ โดยวิธีการแปลงสมการในระบบพิกัดเชิงขั้ว
**วิธีทำ** จากความสัมพันธ์ $r=\sqrt{x^2+y^2}$ จะได้ว่า $\sqrt{x^2+y^2}=1$ หรือ $x^2+y^2=1$
ซึ่งเป็นสมการของวงกลมที่มีรัศมี 1 หน่วย และมีจุดศูนย์กลางอยู่ที่จุดกำเนิด ดังแสดงในรูป 7.4.1

> [Figure] ภาพแสดงกราฟของสมการ $r=1$ ในระบบพิกัดเชิงขั้ว โดยมีแกน x และ y เป็นเส้นตรงและมีจุดกำเนิดอยู่ที่ศูนย์กลาง มีวงกลมที่มีรัศมี 1 หน่วยล้อมรอบจุดกำเนิด ซึ่งเป็นวงกลมที่มีเส้นผ่านศูนย์กลางยาว 2 หน่วยบนแกน x และ 2 หน่วยบนแกน y

**รูป 7.4.1**

**ตัวอย่าง 7.4.2** จงวาดกราฟของสมการ $\theta=\frac{\pi}{3}$ โดยวิธีการแปลงสมการในระบบพิกัดเชิงขั้ว
**วิธีทำ** จากความสัมพันธ์ $\theta=\arctan\frac{y}{x}$ จะได้ว่า $\frac{y}{x}=\tan(\frac{\pi}{3})$ หรือ $y=\sqrt{3}x$
ซึ่งเป็นสมการเส้นตรง ดังแสดงในรูป 7.4.2

> [Figure] ภาพแสดงกราฟของสมการ $\theta=\frac{\pi}{3}$ ในระบบพิกัดเชิงขั้ว โดยมีแกน x และ y เป็นเส้นตรง มีเส้นตรงที่มีความชันเท่ากับ $\sqrt{3}$ ลากจากจุดกำเนิดไปยังจุดใดจุดหนึ่งบนเส้นตรงที่ไม่เป็นจุดกำเนิด ซึ่งเป็นเส้นตรงที่ผ่านจุดกำเนิดและมีเส้นผ่านศูนย์กลางยาว 2 หน่วยบนแกน x และ 2 หน่วยบนแกน y

**รูป 7.4.2**

การวาดกราฟของสมการเชิงขั้วจะมีความถูกต้อง และรวดเร็วยิ่งขึ้นเมื่อเราใช้ความรู้เรื่อง การสมมาตรและจุดตัดของเส้นโค้งเข้าช่วย


7.4.1 การสมมาตรสำหรับกราฟในระบบพิกัดเชิงขั้ว

1.  เรากล่าวว่ากราฟสมมาตรเทียบกับแกน x ถ้าจุด $(r, \theta)$ อยู่บนกราฟ แล้วเมื่อแทนด้วยจุด $(r, -\theta)$ หรือ $(-r, \pi-\theta)$ ยังคงได้จุดที่อยู่บนกราฟ (ดังรูป 7.4.3 ก))
2.  เรากล่าวว่ากราฟสมมาตรเทียบกับแกน y ถ้าจุด $(r, \theta)$ อยู่บนกราฟ แล้วเมื่อแทนด้วยจุด $(r, \pi-\theta)$ หรือ $(-r, \theta)$ ยังคงได้จุดที่อยู่บนกราฟ (ดังรูป 7.4.3 (ข))
3.  เรากล่าวว่ากราฟสมมาตรเทียบกับจุดกำเนิด ถ้าจุด $(r, \theta)$ อยู่บนกราฟ แล้วเมื่อแทนด้วยจุด $(-r, \theta)$ หรือ $(r, \theta+\pi)$ ยังคงได้จุดที่อยู่บนกราฟ (ดังรูป 7.4.3 (ค))

> [Figure] ภาพประกอบแสดงกราฟสามแบบที่แตกต่างกันในระบบพิกัดเชิงขั้ว โดยแต่ละกราฟมีแกน x และแกน y พร้อมจุดกำเนิด O(0)
> กราฟ (ก) แสดงความสมมาตรของเส้นตรงที่เทียบกับแกน x จุดยอดแรกคือ $(r, \theta)$ ซึ่งอยู่บนกราฟ และจุดยอดที่สองคือ $(-r, -\theta)$ ซึ่งเป็นจุดที่เกิดจากการหมุนตำแหน่งของจุดยอดแรกไปทางซ้ายบนแกน x มีเส้นประเชื่อมจุดยอดเหล่านี้เพื่อแสดงความสัมพันธ์ระหว่างกัน ใต้กราฟระบุว่า "(ก) เทียบกับแกน x"
> กราฟ (ข) แสดงความสมมาตรของเส้นตรงที่เทียบกับแกน y จุดยอดแรกคือ $(r, \theta)$ ซึ่งอยู่บนกราฟ และจุดยอดที่สองคือ $(-r, \theta)$ ซึ่งเป็นจุดที่เกิดจากการหมุนตำแหน่งของจุดยอดแรกไปทางซ้ายบนแกน y มีเส้นประเชื่อมจุดยอดเหล่านี้เพื่อแสดงความสัมพันธ์ระหว่างกัน ใต้กราฟระบุว่า "(ข) เทียบกับแกน y"
> กราฟ (ค) แสดงความสมมาตรของวงกลมที่เทียบกับจุดกำเนิด จุดยอดแรกคือ $(r, \theta)$ ซึ่งอยู่บนกราฟ และจุดยอดที่สองคือ $(-r, \theta)$ ซึ่งเป็นจุดที่เกิดจากการหมุนตำแหน่งของจุดยอดแรกไปทางซ้ายบนแกน x มีเส้นประเชื่อมจุดยอดเหล่านี้เพื่อแสดงความสัมพันธ์ระหว่างกัน ใต้กราฟระบุว่า "(ค) เทียบกับจุดกำเนิด"
> โดยรวมแล้ว ภาพนี้แสดงวิธีการตรวจสอบความสมมาตรของกราฟในระบบพิกัดเชิงขั้ว โดยใช้การหมุนตำแหน่งของจุดยอดบนแกน x และ y เพื่อเปรียบเทียบกับจุดกำเนิด

รูป 7.4.3

**หมายเหตุ** กราฟที่สมมาตรเทียบกับทั้งแกน x และแกน y ย่อมสมมาตรเทียบกับจุดกำเนิดด้วย

**ตัวอย่าง 7.4.2** จงวาดกราฟของสมการในระบบพิกัดเชิงขั้ว $r = 2 \cos \theta$

**วิธีทำ** วิธีที่ 1 เราแปลงสมการที่กำหนดให้อยู่ในระบบพิกัดฉาก โดยแทน $r = \sqrt{x^2 + y^2}$ และ $\cos \theta = \frac{x}{\sqrt{x^2 + y^2}}$ ทำให้ได้


$$ \sqrt { x ^ { 2 } + y ^ { 2 } } = \frac { x } { \sqrt { x ^ { 2 } + y ^ { 2 } } $$
นั่นคือ
$x^2 + y^2 = 2x$
ซึ่งจะได้ว่า $(x-1)^2 + y^2 = 1$
เพราะฉะนั้น $(x-1)^2 + y^2 = 1$ เป็นสมการในระบบพิกัดฉากของ $r=2\cos\theta$ ซึ่งเป็นสมการวงกลมรัศมี 1 หน่วย และมีจุดศูนย์กลางอยู่ที่ $(1,0)$ ดังรูป 7.4.4

> [Figure] ภาพแสดงกราฟวงกลมรัศมี 1 หน่วย โดยมีแกน x และแกน y ตัดกันที่จุดกำเนิด (0,0) มีเส้นตรงแนวนอน $y=0$ และเส้นตรงแนวตั้ง $x=0$ ล้อมรอบวงกลม $r=2\cos\theta$ ซึ่งเป็นสมการวงกลมรัศมี 1 หน่วย พร้อมระบุว่า "รูป 7.4.4"

วิธีที่ 2 เราอาจวาดกราฟของสมการเชิงขั้ว $r=2\cos\theta$ โดยวิธีการลงจุด และด้วยวิธีนี้เราจะใช้ $\theta$ ที่มีค่าอยู่ระหว่าง 0 ถึง $\pi$ เนื่องจากค่าของ $\theta$ ที่เพิ่มขึ้นจาก $\pi$ จะทำให้เราได้จุดเดิมอีกครั้ง ดังแสดงในตาราง 7.4.1

แต่กราฟของสมการเชิงขั้ว $r=2\cos\theta$ มีสมมาตรเทียบกับแกน x เพราะเมื่อแทน $\theta$ ด้วย $-\theta$ แล้วสมการ $r=2\cos(-\theta)=2\cos\theta$ ดังนั้นเราสามารถกำหนดค่าของ $\theta$ เพียงครึ่งช่วงคือ $\theta \in [0,\frac{\pi}{2}]$ ก็เพียงพอ ซึ่งจะได้กราฟครึ่งหนึ่งที่อยู่เหนือแกน x และจะวาดกราฟได้แกน x ได้จากการสมมาตร

ตารางด้านล่างแสดงความสัมพันธ์ระหว่างค่า $r$ และ $\theta$ และเมื่อเรานำพิกัด $(r,\theta)$ มาลงจุดแล้วเชื่อมด้วยเส้นโค้งเรียบจะได้เส้นโค้งดังรูป 7.4.5

| $\theta$ | $0$ | $\frac{\pi}{6}$ | $\frac{\pi}{4}$ | $\frac{\pi}{3}$ | $\frac{\pi}{2}$ |
|---|---|---|---|---|---|
| $r = 2\cos\theta$ | $2$ | $\sqrt{3}$ | $\sqrt{2}$ | $1$ | $0$ |

ตาราง 7.4.1

> [Figure] ภาพแสดงกราฟวงกลม $r=2\cos\theta$ ในระบบพิกัดคาร์ทีเซียน โดยมีแกน x และแกน y ตัดกันที่จุดกำเนิด (0,0) กราฟเป็นวงกลมรัศมี 1 หน่วย ที่มีจุดศูนย์กลางอยู่ที่ (1,0) จุดตัดกับแกน x อยู่ที่ $(0,\frac{\pi}{2})$, $(\sqrt{2},\frac{\pi}{4})$, $(\sqrt{3},\frac{\pi}{3})$ และจุดตัดกับแกน y อยู่ที่ $(1,\frac{\pi}{3})$ มีเส้นประแสดงเส้นโค้ง $r=2\cos\theta$ และมีเส้นประแสดงเส้นโค้ง $r=2\sin\theta$ พร้อมระบุว่า "รูป 7.4.5"


ตัวอย่าง 7.4.3 จงตรวจสอบการสมมาตรของกราฟในระบบพิกัดเชิงขั้วต่อไปนี้ $r = \sin\theta$, $r = 1 + \cos\theta$ และ $r = \cos2\theta$

> [Figure] ภาพแสดงกราฟสามแบบในระบบพิกัดคาร์ทีเซียน โดยแต่ละกราฟมีแกน x และ y พร้อมเส้นศูนย์กลางที่กำกับด้วยรูปสัญลักษณ์ '0' ซึ่งเป็นจุดกำเนิด
> (ก) กราฟวงกลมที่มีเส้นรอบวงเป็นเส้นตรงขนานกับแกน y ที่จุดกำเนิด มีสมมาตรตามแกน y เส้นรอบวงคือ $r = \sin\theta$
> (ข) กราฟวงกลมที่มีเส้นรอบวงเป็นเส้นตรงขนานกับแกน x ที่จุดกำเนิด มีสมมาตรตามแกน x เส้นรอบวงคือ $r = 1 + \cos\theta$
> (ค) กราฟดอกไม้ห้าแฉกที่มีเส้นรอบวงเป็นเส้นตรงขนานกับแกน x ที่จุดกำเนิด มีสมมาตรตามแกน x เส้นรอบวงคือ $r = \cos2\theta$

รูป 7.4.6

**วิธีทำ** จากกราฟข้างต้นจะเห็นว่ากราฟรูป 7.4.6 (ก) และ (ค) มีการสมมาตรเทียบกับแกน y เนื่องจาก $\sin(\pi - \theta) = \sin\theta$ และ $\cos2(\pi - \theta) = \cos2\theta$ ในขณะที่กราฟรูป 7.4.6 (ข) และ (ค) มีการสมมาตรเทียบกับแกน x เนื่องจาก $\cos(-\theta) = \cos\theta$ นอกจากนี้เรายังสังเกตได้ว่า กราฟรูป 7.4.6(ค) ยังมีการสมมาตรเทียบกับจุดกำเนิดอีกด้วย เนื่องจาก $\cos2(\pi + \theta) = \cos2\theta$ สรุปก็คือ กราฟของ $r = \sin\theta$ มีการสมมาตรเทียบกับแกน y , กราฟของ $r = 1 + \cos\theta$
มีการสมมาตรเทียบกับแกน x ส่วนกราฟของ $r = \cos2\theta$ มีการสมมาตรเทียบกับ แกน x แกน y และ จุดกำเนิด
